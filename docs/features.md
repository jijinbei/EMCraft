# Commands

Generated by `cargo xtask features` (`emcraft-cli features`). Lengths are in millimetres and frequencies in gigahertz unless the session's display units say otherwise.

## `project.frequency` — Frequency band

The job's frequency band: the default for meshing by wavelength (its top), for sweeps and for port-mode previews.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `start` | number | frequency | yes | the band's start |
| `stop` | number | frequency | yes | the band's stop |

## `project.analysis` — Analysis

The kind of analysis the job is set up for, chosen at its start: `frequency` (S-parameters between ports over the band, solve.frequency), `eigenmodes` (a closed resonator's modes, nothing driving it, solve.eigenmodes), `radiation` (an antenna or a scatterer in an open boundary, solve.radiation) or `time_domain` (a pulse over the band, solve.time_domain). The workflow's checks (project.status) follow it: a resonator needs no excitation and its ports are left out, radiation wants the open boundary and a source or a lumped port, a sweep and the time domain want ports, the time domain no mesh (project.status lists the steps a kind does without under `not_needed`). Until one is chosen the kind is inferred from the model (eigenmodes without excitation, radiation with sources, lumped ports or an open boundary, else a sweep). The results stay as they are. Undo goes back.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `kind` | string |  | yes | `frequency`, `eigenmodes`, `radiation` or `time_domain` |

## `project.status` — Workflow status

Where each step of the workflow stands (intent, geometry, materials, excitation, boundaries, mesh, setup, run, results): done, to do (`todo`), waiting, warning, missing (needs attention) or stale (out of date), each with messages naming the command that fixes it. Reads the model, the mesh and the results; solves nothing.

No parameters.

## `project.estimate` — Solve estimate

How long a run will take, before it starts: `command` with `params` (a solve, mesh.adapt, study.sweep or study.optimize), else the project's latest run, else a sweep of the band. The total `seconds` (the frequencies of a sweep — a fast sweep solving a few in full —, the eigenmodes, the adaptive passes, the time domain's cells and steps, a study's points), what it counts (`what`), and for a frequency-domain solve the meshed model's unknowns at `order`, the factor's memory and the seconds of one solve. `basis` says where the numbers come from: `measured` (scaled from this session's own last sweep, on this machine) or `reference` (a reference machine's). Reads the model only: cheap, and the same set-up gives the same numbers.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `order` | integer |  | no | element order, 1 or 2 (default the run's, else 2) |
| `command` | string |  | no | the run to estimate: a solve command, mesh.adapt, study.sweep or study.optimize (default the latest run) |
| `params` | object |  | no | its parameters, as the command takes them |

## `file.save` — Save project

Saves the project as an `.emcraft` file (JSON: the commands that built the model, a script; the last run of each solve command with its parameters, not its results; and the model), to `path` or, without one, to the file it was opened from or last saved to. A path without an extension gets `.emcraft`. With `copy` it writes a copy to `path` and leaves the project's own file, name and unsaved state as they were (an autosave).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | no | the file (default: the project's own; required with `copy`) |
| `copy` | boolean |  | no | write a copy only: the project keeps its file and stays unsaved (default false) |

## `file.new` — New project

Replaces the session with an empty project (vacuum only), keeping the display units; undo goes back.

No parameters.

## `file.open` — Open project

Opens a project saved by file.save (`.emcraft`, or a `.json` of the same form): its commands are replayed, so the mesh comes back the same; its runs (project.runs) come back without running, and results are solved again (solve.rerun). With `original`, `path` is a copy of that project (an autosave being recovered): the project takes the original's file, unsaved where it differs from what that file holds. Undo goes back to the project before, its file included.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | yes | the file |
| `original` | string |  | no | the project file `path` is a copy of: the project's own file from now on |

## `project.runs` — Runs

The project's runs: the last solve of each solve command that succeeded, the latest last, each with its parameters in the display units now (as the command takes them: they reproduce the run) and the units it was given in. Saved with the project and restored by file.open without running them; a run with other parameters than the saved one leaves the project unsaved.

No parameters.

## `project.values` — Current values

The parameters that reproduce the model's current state for `command`, in the display units now, for an edit dialog to open on: the band, the units, the device, the walls, the open boundary, a symmetry plane (`axis`, default the first), the periodic boundaries, the waveguide, a primitive solid; an item's for its edit command (`name` a material's or a port's, `body` a body's, `index` a source's); the mesh commands' as the history last ran them; a solve command's as its last run (project.runs). Running the command with them leaves the model as it is (an item edit to the last bit). A command with no current state gives an empty object.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `command` | string |  | yes | the command, such as `model.walls` or `model.port.edit` |
| `name` | string |  | no | the item of an item's edit command: a material's or a port's name |
| `body` | string |  | no | geometry.body.edit's body |
| `index` | integer |  | no | source.edit's source, 1 = the first |
| `axis` | string |  | no | model.symmetry's plane: `x` or `y` (default the first there is) |

## `edit.undo` — Undo

Goes back to the model before the last change (results stay, marked stale). Undoing file.open, file.new or file.sample brings the project before it back whole: its file, its unsaved state, its runs and their results.

No parameters.

## `edit.redo` — Redo

Goes forward again after an undo.

No parameters.

## `results.touchstone` — Export Touchstone

Writes the sweep's S-parameters as a Touchstone (version 1) file, frequencies in GHz, the ports' reference impedance on the option line; one port per entry of S (each terminal of a terminal port, in the order `ports` lists them).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | yes | the file (.s1p, .s2p, …) |
| `format` | string |  | no | `ri` (default) or `ma` |

## `results.check` — Check results

The sweep's physics checks: passivity (the largest singular value of S over the frequencies, ≤ 1 when passive), reciprocity (max |S − Sᵀ|) and unitarity (max |SᴴS − 1|, 0 when lossless).

No parameters.

## `model.material.create` — Create material

A linear, isotropic material, lossless unless it has a loss tangent (dielectric or magnetic) or dispersion. A dispersive material's permittivity is ε(ω) = εr(1 − j tan δ) + Σ χ_k(ω) over its Debye, Lorentz and Drude poles (time dependence e^{jωt}, so ε = ε′ − jε″; Taflove & Hagness, Computational Electrodynamics, 3rd ed., ch. 9); εr is then ε∞. Its permeability is μr(1 − j tan δm). The frequency-domain solver takes ε(ω) at each frequency, the time-domain solver its poles by auxiliary differential equations and its loss tangents as conductivities matched at the centre of its band (exact there, tan δ·f_ref/f elsewhere). A port may lie in a lossy or dispersive material that fills its cross-section, or cross several materials one of which is lossy or dispersive (a microstrip or stripline on a lossy substrate: hybrid lossy modes solved on the cross-section at each frequency): its modes then attenuate (γ = α + jβ) and S is read as pseudo-waves referred to each port's wave impedance (Marks & Williams 1992); eigenmode cavities may not be filled with a dispersive material.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | yes | unique name |
| `eps_r` | number |  | yes | relative permittivity εr > 0 (ε∞ with dispersion) |
| `mu_r` | number |  | no | relative permeability μr > 0 (default 1) |
| `loss_tangent` | number |  | no | dielectric loss tangent tan δ, 0 to 1e9 (default 0): ε = εr(1 − j tan δ) |
| `magnetic_loss_tangent` | number |  | no | magnetic loss tangent tan δm, 0 to 1e9 (default 0): μ = μr(1 − j tan δm) |
| `debye` | array | frequency | no | Debye poles `[{"delta_eps", "frequency"}]`: χ = Δε/(1 + jω/ω_r), Δε > 0, relaxation frequency f_r = 1/(2πτ) > 0 (frequency) |
| `lorentz` | array | frequency | no | Lorentz poles `[{"delta_eps", "frequency", "damping"}]`: χ = Δε ω₀²/(ω₀² − ω² + jωγ), Δε > 0, resonance f₀ = ω₀/2π > 0, damping γ/2π > 0 (frequencies) |
| `drude` | array | frequency | no | Drude poles `[{"plasma_frequency", "damping"}]`: χ = −ω_p²/(ω² − jωγ), plasma frequency ω_p/2π > 0, damping γ/2π > 0 (frequencies) |

Changes only the parameters given and checks the material again; a new name alone keeps every result, any other change drops them (the mesh stays: mesh again when it was sized by wavelength). Undo goes back.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | yes | the material |
| `rename` | string |  | no | a new name, unique |
| `eps_r` | number |  | no | relative permittivity εr > 0 (ε∞ with dispersion) |
| `mu_r` | number |  | no | relative permeability μr > 0 |
| `loss_tangent` | number |  | no | dielectric loss tangent tan δ, 0 to 1e9 |
| `magnetic_loss_tangent` | number |  | no | magnetic loss tangent tan δm, 0 to 1e9 |
| `debye` | array | frequency | no | Debye poles `[{"delta_eps", "frequency"}]`, replacing the material's (frequency) |
| `lorentz` | array | frequency | no | Lorentz poles `[{"delta_eps", "frequency", "damping"}]`, replacing the material's (frequencies) |
| `drude` | array | frequency | no | Drude poles `[{"plasma_frequency", "damping"}]`, replacing the material's (frequencies) |

## `geometry.waveguide` — Rectangular waveguide

A rectangular waveguide along z with perfectly conducting walls: cross-section `width` (x) × `height` (y) from the origin, filled along z in sections, each with its own aperture across x (H-plane steps, inductive irises; neighbouring apertures must nest). A shielded planar circuit is one too: `layers` fill it from y = 0 up (a substrate), `strips` of no thickness lie on planes y = const (a microstrip on the substrate's top, a stripline between two layers; strips may end inside the box: open stubs, a stub branching off a line), `vias` are conducting posts (a via to ground, a shorting pin); its ports then take their modes from the cross-section solver. Replaces any geometry, mesh and results.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `width` | number | length | yes | broad wall a (x) |
| `height` | number | length | yes | narrow wall b (y) |
| `sections` | array |  | yes | `[{"length", "material", "width"?, "offset"?}]` from z = 0: a section may narrow the broad wall to an aperture `width` wide (lengths), starting at x = `offset` (centred when left out) |
| `layers` | array |  | no | `[{"thickness", "material"}]` from y = 0 up, across the whole guide (lengths); above them each section's material |
| `strips` | array |  | no | `[{"y", "x0", "width", "z0"?, "z1"?}]`: conducting strips of no thickness, [x0, x0 + width] × [z0, z1] on the plane y (lengths; z0, z1 the guide's ends when left out); strips on one plane meet edge to edge (one conductor: a T, a step in width) or keep a gap of at least 1e-4 of the guide, never overlap: side by side a gap apart they are coupled lines (a port holding n strips has n quasi-TEM modes, even and odd for two) |
| `vias` | array |  | no | `[{"x0", "z0", "wx", "wz", "y0"?, "y1"?}]`: conducting rectangular posts [x0, x0 + wx] × [y0, y1] × [z0, z0 + wz], solid metal (lengths; y0 = 0 and y1 = the height when left out: a post from the ground plane, through a strip on its way, to the top); a via from the ground to a strip ends at the strip's y |

## `geometry.iris_filter` — Iris filter

A rectangular waveguide along z (`width` × `height`, perfectly conducting walls) with a row of `irises` inductive irises: a feed, the irises (apertures centred across x, each `iris_length` long) with a cavity between each two, a feed. The first and last irises are `end_width` wide and the cavities next to them `cavity` long; those between are `inner_width` wide and `inner_cavity` long (the end ones' when left out). Replaces any geometry, mesh and results.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `width` | number | length | yes | broad wall a (x) |
| `height` | number | length | yes | narrow wall b (y) |
| `irises` | integer |  | yes | irises, 2 to 32 |
| `iris_length` | number | length | yes | each iris's length along z |
| `end_width` | number | length | yes | the first and last irises' aperture |
| `inner_width` | number | length | no | the other irises' aperture (default `end_width`) |
| `cavity` | number | length | yes | the cavities next to the first and last irises: their length |
| `inner_cavity` | number | length | no | the other cavities' length (default `cavity`) |
| `feed` | number | length | yes | the guide's length before the first iris and after the last |
| `material` | string |  | no | what fills it (default `vacuum`) |

## `geometry.solid` — Primitive body

A body of one material with conducting walls, meshed with unstructured tetrahedra: a box [0, x] × [0, y] × [0, z] (`size`), a cylinder about z from z = 0 (`radius`, `length`), a sphere about the origin (`radius`) or a prism, the simple polygon `points` of the plane z = 0 extruded to z = `length` (the outline of a bend, a mitred corner or a junction of guides). Its end faces (z = 0, z = length) can carry ports, and so can its other flat faces across x, y or z (model.port.create with `face` and `axis`); a closed body is a cavity for `solve.eigenmodes`. Replaces any geometry, mesh and results.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `shape` | string |  | yes | `box`, `cylinder`, `sphere` or `prism` |
| `size` | array | length | no | the box's [x, y, z] |
| `radius` | number | length | no | the cylinder's or the sphere's radius |
| `length` | number | length | no | the cylinder's or the prism's length along z |
| `points` | array | length | no | the prism's outline: its corners [x, y] in order (a simple polygon, at most 256), in its own plane z = 0 |
| `material` | string |  | no | the filling (default vacuum) |

## `geometry.import` — Import

Reads a part: an STL file (one body) or a 3MF package, such as SolidCraft's export with face tags (one body per build item, named after its object, its B-rep faces kept as faces; objects made of components flattened, their transforms composed, and objects in other model parts of the package read). Each face's exact surface (plane, cylinder, sphere, cone, torus) is recovered from its vertices where one fits them to 1e-6 of the body's size, so second-order elements bend onto curved faces; the reply counts them under `curved`. Triangles are grouped into faces also by the angle between neighbours, so sharp edges stay edges. One body alone becomes the region the fields fill, filled with `material`, and its faces on its lowest and highest z planes can carry ports. Several bodies lie in a box of air (`material`) `margin` beyond them all, or in the body `region` names; each is metal unless `materials` gives it another (geometry.body.material changes it later). With `region` `cavity` the part is drawn as its metal (a block with a channel milled through it): the region is the air the metal bodies enclose — their bounding box less them, split into connected pieces, each piece kept that reaches no side (x or y) of the box (it may reach the lowest and highest z, where a channel's ports go), the air around a part that is not a box dropped; `keep` `largest` keeps only the largest piece. The metal bodies become the region's walls, bodies of other materials lie in it. With `open` (an antenna, a scatterer) the box is lined by a perfectly matched layer as model.open does: by default a quarter of the band's longest wavelength of air between the parts and the layer, and a layer as thick. Replaces any geometry, mesh and results.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | yes | the file (`.stl`, `.3mf`, a SolidCraft design `.sc` or `.solidcraft`), or `template:<file>`: a design a template is built from, compiled in |
| `unit` | number | length | no | an STL file's length unit in display units (default 1, i.e. the display unit); 3MF files carry their own |
| `angle` | number |  | no | neighbouring triangles turning by more than this many degrees are on different faces (default 30) |
| `material` | string |  | no | the region's filling (default vacuum) |
| `region` | string |  | no | `box` (air around the bodies; the default for several), `cavity` (the air the metal bodies enclose) or the name of the body that is the region (the default for one) |
| `keep` | string |  | no | with `region` `cavity`: `enclosed` (every piece of air the metal encloses, the default) or `largest` (the largest alone) |
| `margin` | number | length | no | the box's room around the bodies, the layer included (default a quarter of their largest extent; with `open`, a quarter wavelength of air and the layer) |
| `materials` | object |  | no | body name → material, or `metal` (the default for every body) |
| `open` | boolean |  | no | an open problem: line the box of air with a perfectly matched layer (default false) |
| `thickness` | number | length | no | the layer's thickness with `open` (default a quarter of the band's longest wavelength) |
| `fit_surfaces` | boolean |  | no | recover each face's exact surface — a plane, cylinder, sphere, cone or torus fitted to its vertices, kept when every vertex lies on it — so the mesh follows curved faces as it does native ones (default true); false keeps them faceted |
| `parameters` | object |  | no | a SolidCraft design (.sc, .solidcraft) only: its parameters set before it is evaluated, name → a number in the unit the design shows it in, an expression of the project's variables read as such a number ("=a"), or an expression the design evaluates ("3 mm"); its faces then carry the design's exact surfaces, not fitted ones |
| `tolerance` | number | length | no | a SolidCraft design only: the chord tolerance of its tessellation (default 2e-4 of each body's size) |

## `geometry.body` — Body

## `geometry.feature` — Combine a body

Combines a primitive with the solid: `add` (union: a stub, a housing), `subtract` (difference: a post, a screw, a notch; its surface becomes conducting wall) or `intersect`. ## `geometry.measure` — Measure

The distance between two picked points (`from`, `to`) and its components Δx, Δy, Δz. A point picked on a face may bring the face's normal (`from_normal`, `to_normal`: a plane through the point), one picked on a straight edge its direction (`from_along`, `to_along`: a line through it); then the perpendicular distance `gap` (two parallel faces, a point and a face, a point and an edge, two parallel edges, an edge along a face) and the `angle` between them (two faces, two edges, an edge and a face; degrees, 0 to 90) come too. Changes nothing.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `from` | array | length | yes | the first point [x, y, z] |
| `to` | array | length | yes | the second point [x, y, z] |
| `from_normal` | array |  | no | the normal of the face the first point lies on |
| `to_normal` | array |  | no | the normal of the face the second point lies on |
| `from_along` | array |  | no | the direction of the edge the first point lies on |
| `to_along` | array |  | no | the direction of the edge the second point lies on |

## `mesh.generate` — Mesh

Meshes the waveguide with tetrahedra of about `size` on a side (six per cell of a structured grid; every section boundary and aperture wall is a grid plane), graded towards the re-entrant edges of steps and irises. A solid is meshed without structure, its tetrahedra on curved walls and interfaces curved (quadratic geometry) unless `curved` is false.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `size` | number | length | no | target element size (required without `per_wavelength`; with it, the largest size) |
| `per_wavelength` | number |  | no | elements per wavelength in each material at `frequency` (λ = c/(f√(εr μr))): a solid's regions each at their own size, a waveguide at the smallest |
| `frequency` | number | frequency | no | the highest frequency the mesh must resolve (with `per_wavelength`) |

## `mesh.adapt` — Adaptive mesh

Refines the mesh in passes until the S-parameters (or an open problem's far field) settle: each pass meshes, solves at `frequency` and compares S with the previous pass (ΔS, the largest change of any entry); it stops when ΔS < `tolerance`, after `passes`, or before the next mesh would pass the tetrahedra or unknowns limit (the last that fitted stays). A solid is refined where a residual error indicator is largest (the jumps of tangential μ⁻¹∇×E and normal εE across faces and the element residual, summed over the ports' excitations): the fewest tetrahedra holding `fraction` of its total are meshed again at half their size, graded smoothly. A structured waveguide grid is refined uniformly instead (the size divided by 1.4 a pass). Open problems (model.open) are adapted too, each pass solved as solve.radiation solves it: the indicator leaves out the perfectly matched layer (never refined, so it keeps its thickness and the size it was meshed at) and the tetrahedra at a current element or a line gap, and takes a plane wave's incident field as the scattered field's data; with lumped ports or a waveguide feed the passes compare their reflections (ΔS), with sources alone the far field (`quantity` far_field in the reply). The final mesh stays; solve it with solve.frequency (open problems: solve.radiation).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `size` | number | length | no | the first pass's element size (required without `per_wavelength`) |
| `per_wavelength` | number |  | no | the first pass's elements per wavelength in each material at `frequency` |
| `frequency` | number | frequency | no | the frequency to adapt at (default: the band's top) |
| `passes` | integer |  | no | the most passes, 1 to 12 (default 6) |
| `tolerance` | number |  | no | converged when the change from the previous pass is below this (default 0.02): ΔS, the largest change of any S entry (open problems: of the lumped ports' and the feed's reflections); for an open problem driven by sources alone (dipoles, a plane wave), the far field's relative change ‖F − F′‖/‖F′‖ of r e^{jkr}(E_θ, E_φ) over 48 directions (θ 15° to 165° every 30°, φ every 45°), which tracks the radiated or scattered power and the pattern |
| `fraction` | number |  | no | Dörfler's θ in (0, 1]: refine the fewest tetrahedra holding this share of the error (default 0.3) |
| `order` | integer |  | no | element order: 1 or 2 (default) |
| `curved` | boolean |  | no | solids: bend the edges on curved surfaces onto them (default true) |
| `edge` | number |  | no | waveguides: element size at step and iris edges, as a fraction of the size (default 0.25) |
| `growth` | number |  | no | waveguides: element growth away from those edges (default 1.5) |
| `strip_edge` | number |  | no | waveguides: element size at strips' edges, as a fraction of the size (default 0.05) |
| `strip_end` | number |  | no | waveguides: element size at strips' ends along z, as a fraction of the size (default `strip_edge`) |
| `size_y` | number | length | no | waveguides: element size across the narrow wall (default the size; kept through the passes) |

## `model.walls` — Walls

The conductivity and thickness of the guide's walls, irises and steps. The metal is never meshed: only the inside is, and the walls are a surface impedance on it, so a thickness costs no unknowns. With `conductivity`, losses by the Leontovich condition (good conductors, skin depth far below the guide), through a wall of `thickness` with free space behind it (Z_s = η_c(η₀ + η_c tanh γt)/(η_c + η₀ tanh γt): thinner than a few skin depths it loses more; the time-domain solver takes walls as thick). Without `conductivity` the walls are perfect conductors; the thickness is then drawn round the guide only. Leave `thickness` out for infinitely thick walls drawn flush.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `conductivity` | number |  | no | σ in S/m (copper 5.8e7); leave out for perfect conductors |
| `thickness` | number | length | no | the walls' thickness; leave out for infinitely thick walls |

## `model.symmetry` — Symmetry plane

Cuts a waveguide symmetric about its middle (x = a/2 or y = b/2) on that plane: only the side below it is meshed and solved, the plane closed by an electric wall (a perfect conductor: tangential E = 0, the fields whose tangential E is odd about it) or a magnetic wall (tangential H = 0, normal E = 0: the fields whose tangential E is even). TE10 is kept by a magnetic wall at x = a/2 and an electric wall at y = b/2, so an H-plane iris or filter solves on a quarter with the whole model's S-parameters; ports carry only the modes of the kept parity, fields beyond the plane are shown as the images of those inside. One plane per axis (a new one replaces the old); `clear` removes one (`axis`) or all. Waveguides only; the time-domain solver refuses symmetry planes. Drops the mesh.

|---|---|---|---|---|

| `kind` | string |  | no | `electric` (PEC wall) or `magnetic` (PMC wall) |
| `at` | number | length | no | the plane's position (default the guide's middle, the only one allowed) |
| `clear` | boolean |  | no | remove the plane across `axis`, or every plane without it |

## `model.periodic` — Periodic boundaries

Makes the model the unit cell of an infinite array: the faces x = 0 and x = a (`x`), y = 0 and y = b (`y`) or z = 0 and z = length (`z`) tied by Floquet's condition E(r + L) = e^{−jψ}E(r) (master/slave elimination; the system is then solved by LU, being Hermitian rather than complex symmetric). Across x and y the phases come from a plane wave incident at `theta` from the z axis and azimuth `phi` from x, in the first port's medium; the ports on the cell's ends become Floquet ports (the harmonics TE and TM (m, n), the (0, 0) of `polarization` excited and read, the rest absorbing). Along z the cell is a period of a guide whose dispersion `solve.dispersion` finds (no ports). Waveguide geometries only (the structured mesh's opposite faces match); not with symmetry planes, open boundaries, lumped ports or the time domain. `clear` removes them.

| `x` | boolean |  | no | tie x = 0 and x = a (default true; as before when set) |
| `y` | boolean |  | no | tie y = 0 and y = b (default true) |
| `z` | boolean |  | no | tie z = 0 and z = length (default false; no ports then) |
| `theta` | number |  | no | incidence angle from the z axis in degrees, 0 to below 90 (default 0) |
| `phi` | number |  | no | incidence azimuth from the x axis in degrees (default 0) |
| `polarization` | string |  | no | `te` (E across the plane of incidence, default) or `tm` |
| `clear` | boolean |  | no | remove the periodic boundaries |

## `model.port.create` — Create port

A waveguide port on an end face, matched to the guide's lowest modes. The first mode (TE10 in a rectangular guide, TEM in a coaxial line) is excited and read; the other modes absorb what else reaches the port. A whole rectangle or circle of one material takes the closed-form modes; any other cross-section — a coaxial line, a ridged guide, an imported polygon — has its modes solved on its triangles at each frequency (`mode_solver` numeric forces that everywhere). With `face` the port is a rectangle of an axis plane of a solid instead — across z by default, across x or y with `axis` (an arm of a bend or a tee ending on a side of the solid, a guide's closed end inside a body feeding an antenna in an open box); `end` then says which side of the plane the guide lies (start: above it along the axis, end: below it). Its modes are the rectangle's along its own sides, in the order x, y, z (an x face: a along y, b along z; a y face: a along x, b along z). A cross-section holding several strips (coupled lines) is a terminal port: one S entry per strip, `<port>:1`, `<port>:2`, … from the lowest x, its quasi-TEM modes (one per strip, all excited) converted to the strips' voltages and currents and their waves referred to `impedance` (50 Ω by default); `terminals` modal reads its first mode only (and is needed in a lossy cross-section, where terminal ports are not supported yet).

| `modes` | integer |  | no | modes in the port condition, 1 to 32 (default 4) |
| `face` | array | length | no | [at, u0, v0, a, b]: the rectangle [u0, u0 + a] × [v0, v0 + b] of the plane at `at` across `axis`, u and v its other two axes in the order x, y, z (across z: [z, x0, y0, a, b]) |
| `axis` | string |  | no | the axis `face` lies across: `x`, `y` or `z` (default) |
| `mode_solver` | string |  | no | `auto` (default: closed forms where they apply) or `numeric` (the cross-section solver) |
| `impedance` | number |  | no | the reference impedance (Ω) S is referred to here, for a line with one (coaxial, strip); the line's own when left out |
| `deembed` | number | length | no | de-embedding: how far inside the model S's reference plane lies from the port's face, along its line (negative: a line added outside); default 0 |

## `solve.frequency` — Frequency sweep

Solves the driven problem at each frequency, every port excited in turn by a unit wave of its first mode (TE10 in a rectangular guide), a terminal port by each of its strips' modes (S then has an entry per strip, `ports` names them): S-parameters and fields. ## `solve.time_domain` — Time domain

The S-parameters (port 1 excited) by the time-domain solver: finite integration on a hexahedral grid of cells about `cell` on a side, a TE10 pulse over the band, PML-terminated feeds, Fourier transforms at the frequencies. An independent check of the frequency-domain FEM. Losses: a loss tangent (dielectric or magnetic) becomes a conductivity matched at the band's centre (`loss_reference` in the reply), so the material solved is εr − jσ/ω, tan δ exactly there and tan δ·f_ref/f elsewhere; walls of finite conductivity (model.walls) take the surface-impedance condition; ports may be lossy or dispersive (their complex propagation constant normalises S). For an open model (model.open) it solves the antenna instead: its lumped ports and dipoles on a uniform grid with a CPML on all sides, the ports' impedances and S11 and the radiated power at each frequency, the far field from a Huygens box (results.far_field and view.pattern with `solver` time_domain), with lossy, dispersive and magnetic bodies but perfect conductors. Gaps and dipoles must lie along grid axes; gaps in lossy or dispersive materials are refused.

| `start` | number | frequency | no | first frequency |
| `stop` | number | frequency | no | last frequency |
| `points` | integer |  | no | frequencies from start to stop (default 101) |
| `cell` | number | length | no | the cell size (default 1 mm) |
| `device` | string |  | no | where the leapfrog runs: `cpu` (the CPU's threads), `cuda` (an NVIDIA GPU) or `cubecl-cpu` (the GPU's kernels on the CPU, to check them without a GPU); default solve.device's; solve.devices lists what this machine has |

## `model.open` — Open boundary

Lines every face of a box solid with a perfectly matched layer of `thickness` (conducting walls behind it), for radiation and scattering: an anisotropic medium of stretched coordinates, s = 1 − j(σ₀/k₀)(ξ/d)², designed for 1e-6 reflection at normal incidence. With `shape` sphere the solid is a sphere (centred on the origin) and its outer shell of that thickness is the layer, stretched along the radius only (r̃ = r + (1/jk₀)∫σ dr; the mesh gets an interface sphere at the layer's inner radius) — less volume round a compact radiator than a box's, and the Huygens surface a sphere inside it; sources, lumped ports and inclusions inside the inner sphere, no waveguide ports or features. A quarter to half a wavelength is typical; leave as much again between what radiates and the layer (the Huygens surface for the far field lies between them, and wants a couple of elements' distance from sources' near fields). Without `thickness`, closes the box again.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `thickness` | number | length | no | the layer's thickness |
| `reflection` | number |  | no | the reflection at normal incidence the layer's profile is designed for, 0 to 1 (default 1e-6) |
| `shape` | string |  | no | `box` (default: slabs on a box solid's faces) or `sphere` (the outer shell of a sphere solid) |

## `study.optimize` — Optimize

Finds the variables' values within their bounds that minimize a goal, by the Nelder–Mead simplex (Comput. J. 7(4):308–313, 1965) on the range scaled to [0, 1], from the current values; each point is the model rebuilt from the history and solved by `solve`. Goals (`type`): `min_max_db` (the largest |S| over the frequencies, default s11: a reflection), `max_min_db` (the smallest |S|, default s21: a transmission), `target_db` (|S| at `target` dB), `eigenfrequency` (mode `mode`, default 1, at `target` in display units), `maximize` or `minimize` (a number the solve gives: `quantity`). The model is left at the best point (undo goes back); every evaluation is kept.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `variables` | array |  | yes | the variables varied: [{"name", "min", "max"}] (at most 8) |

| `solve` | object |  | yes | the solve at each point: {"command", "params"} |
| `max_evaluations` | integer |  | no | the most solves (default 50, at most 500) |
