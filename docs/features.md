# Commands

Generated by `cargo xtask features` (`emcraft-cli features`). Lengths are in millimetres and frequencies in gigahertz unless the session's display units say otherwise.

## `units.set` — Display units

Sets the units parameters are read in and replies written in.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `length` | string |  | no | `mm` or `m` |
| `frequency` | string |  | no | `GHz`, `MHz` or `Hz` |

## `model.material.create` — Create material

A linear, isotropic material, lossless unless it has a loss tangent.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | yes | unique name |
| `eps_r` | number |  | yes | relative permittivity εr > 0 |
| `mu_r` | number |  | no | relative permeability μr > 0 (default 1) |
| `loss_tangent` | number |  | no | dielectric loss tangent tan δ ≥ 0 (default 0): ε = εr(1 − j tan δ) |

## `geometry.waveguide` — Rectangular waveguide

A rectangular waveguide along z with perfectly conducting walls: cross-section `width` (x) × `height` (y) from the origin, filled along z in sections, each with its own aperture across x (H-plane steps, inductive irises; neighbouring apertures must nest). Replaces any geometry, mesh and results.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `width` | number | length | yes | broad wall a (x) |
| `height` | number | length | yes | narrow wall b (y) |
| `sections` | array |  | yes | `[{"length", "material", "width"?, "offset"?}]` from z = 0: a section may narrow the broad wall to an aperture `width` wide (lengths), starting at x = `offset` (centred when left out) |

## `geometry.solid` — Primitive body

A body of one material with conducting walls, meshed with unstructured tetrahedra: a box [0, x] × [0, y] × [0, z] (`size`), a cylinder about z from z = 0 (`radius`, `length`) or a sphere about the origin (`radius`). Its end faces (z = 0, z = length) can carry ports; a closed body is a cavity for `solve.eigenmodes`. Replaces any geometry, mesh and results.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `shape` | string |  | yes | `box`, `cylinder` or `sphere` |
| `size` | array | length | no | the box's [x, y, z] |
| `radius` | number | length | no | the cylinder's or the sphere's radius |
| `length` | number | length | no | the cylinder's length along z |
| `material` | string |  | no | the filling (default vacuum) |

## `geometry.import` — Import a surface

A body bounded by a closed triangulated surface read from an STL (binary or ASCII) or 3MF file, meshed with unstructured tetrahedra like geometry.solid. Its triangles are grouped into faces by the angle between neighbours, so its sharp edges stay edges. The faces on its lowest and highest z planes can carry ports when they are a whole rectangle or a disc. Replaces any geometry, mesh and results.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | yes | the file (`.stl` or `.3mf`) |
| `unit` | number | length | no | an STL file's length unit in display units (default 1, i.e. the display unit); 3MF files carry their own |
| `angle` | number |  | no | neighbouring triangles turning by more than this many degrees are on different faces (default 30) |
| `material` | string |  | no | the filling (default vacuum) |

## `geometry.inclusion` — Inclusion

A body inside the solid: a dielectric region (`material`) or, without one, a conductor. The same shapes as geometry.solid, placed with their origin at `at`; it must lie inside the solid, apart from other inclusions. The regions are meshed apart and joined node for node across the interface.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `shape` | string |  | yes | `box`, `cylinder` or `sphere` |
| `size` | array | length | no | the box's [x, y, z] |
| `radius` | number | length | no | the cylinder's or the sphere's radius |
| `length` | number | length | no | the cylinder's length along z |
| `at` | array | length | no | where its origin goes (default [0, 0, 0]) |
| `material` | string |  | no | its filling; a perfect conductor when left out |

## `geometry.feature` — Combine a body

Combines a primitive with the solid: `add` (union: a stub, a housing), `subtract` (difference: a post, a screw, a notch; its surface becomes conducting wall) or `intersect`. The same shapes as geometry.solid, its origin at `at` and its z axis turned onto `axis`. Faces flush with the solid's are handled (a post may run wall to wall); the surfaces must otherwise meet cleanly. A port's end face must stay whole.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `combine` | string |  | yes | `add`, `subtract` or `intersect` |
| `shape` | string |  | yes | `box`, `cylinder` or `sphere` |
| `size` | array | length | no | the box's [x, y, z] (in its own axes) |
| `radius` | number | length | no | the cylinder's or the sphere's radius |
| `length` | number | length | no | the cylinder's length along its axis |
| `at` | array | length | no | where its origin goes (default [0, 0, 0]) |
| `axis` | string |  | no | `x`, `y` or `z` (default): where its own z axis points |

## `mesh.generate` — Mesh

Meshes the waveguide with tetrahedra of about `size` on a side (six per cell of a structured grid; every section boundary and aperture wall is a grid plane), graded towards the re-entrant edges of steps and irises. A solid is meshed without structure, its tetrahedra on curved walls and interfaces curved (quadratic geometry) unless `curved` is false.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `size` | number | length | no | target element size (required without `per_wavelength`; with it, the largest size) |
| `per_wavelength` | number |  | no | elements per wavelength in each material at `frequency` (λ = c/(f√(εr μr))): a solid's regions each at their own size, a waveguide at the smallest |
| `frequency` | number | frequency | no | the highest frequency the mesh must resolve (with `per_wavelength`) |
| `edge` | number |  | no | element size at step and iris edges, as a fraction of `size` (default 0.25; 1 = uniform) |
| `growth` | number |  | no | element growth away from those edges (default 1.5) |
| `size_y` | number | length | no | element size across the narrow wall (default `size`); an H-plane device's TE10 fields do not vary along y, so one layer (the height) is exact there |
| `curved` | boolean |  | no | solids: bend the edges on curved surfaces onto them (default true; false leaves flat facets inscribed in the surface) |

## `model.walls` — Wall conductivity

The conductivity of the guide's walls, irises and steps: losses by the Leontovich surface-impedance condition (good conductors, skin depth far below the guide). Without `conductivity` the walls are perfect conductors.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `conductivity` | number |  | no | σ in S/m (copper 5.8e7); leave out for perfect conductors |

## `model.port.create` — Create port

A waveguide port on an end face, matched to the guide's lowest modes. TE10 is excited and read; the other modes absorb what else reaches the port. With `face` the port is a rectangle of a z plane inside a solid instead — a guide's closed end inside a body, say, feeding an antenna in an open box; `end` then says which side of the plane the guide lies (start: above it, end: below it).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | yes | unique name |
| `end` | string |  | yes | `start` (z = 0) or `end` (z = length); with `face`, the side the guide lies |
| `modes` | integer |  | no | modes in the port condition, 1 to 32 (default 4) |
| `face` | array | length | no | [z, x0, y0, a, b]: the rectangle [x0, x0 + a] × [y0, y0 + b] of the plane at z |

## `solve.frequency` — Frequency sweep

Solves the driven problem at each frequency, every port excited in turn by a unit TE10 wave: S-parameters and fields. Frequencies are `frequencies`, or `points` evenly from `start` to `stop`.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `frequencies` | array | frequency | no | the frequencies |
| `start` | number | frequency | no | first frequency |
| `stop` | number | frequency | no | last frequency |
| `points` | integer |  | no | frequencies from start to stop (default 11) |
| `order` | integer |  | no | element order: 1 (Whitney) or 2 (default) |

## `solve.time_domain` — Time-domain solve

The S-parameters (port 1 excited) by the time-domain solver: finite integration on a hexahedral grid of cells about `cell` on a side, a TE10 pulse over the band, PML-terminated feeds, Fourier transforms at the frequencies. An independent check of the frequency-domain FEM; lossless models only.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `frequencies` | array | frequency | no | the frequencies |
| `start` | number | frequency | no | first frequency |
| `stop` | number | frequency | no | last frequency |
| `points` | integer |  | no | frequencies from start to stop (default 11) |
| `cell` | number | length | no | the cell size (default 1 mm) |

## `solve.eigenmodes` — Eigenmodes

The resonances of the guide closed at both ends by conducting walls (a cavity; ports are left out): the `count` modes nearest `near`, with Q factors from the walls' conductivity and the dielectrics' loss tangents by perturbation. Put `near` a little above the modes wanted: modes up to about √2 times it are found before the curl's null space.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `near` | number | frequency | yes | the frequency the modes are sought around |
| `count` | integer |  | no | modes, 1 to 50 (default 5) |
| `order` | integer |  | no | element order: 1 or 2 (default) |

## `results.eigenmodes` — Eigenmode table

The eigenmodes' frequencies and Q factors; for a cavity of one uniform section, the closed-form resonances too.

No parameters.

## `results.sparameters` — S-parameters

The S-parameter table of the last sweep: each S[p][q] (at port p for a wave into port q) as real, imaginary, magnitude, dB and phase (degrees).

No parameters.

## `results.compare` — Compare with theory

Compares the sweep's S11 and S21 with the reference: the exact TE10 solution when every section has the full cross-section, mode matching (`modes` TE_m0 modes in the widest section) when the aperture changes. The errors per frequency and the worst.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `modes` | integer |  | no | TE_m0 modes in the widest section for mode matching, 10 to 1000 (default 160) |

## `results.field_error` — Field error against theory

The relative L2 errors ‖F − F_exact‖/‖F_exact‖ of E and H over the whole guide at a solved frequency, against the exact TE10 fields (port 1 excited).

## `model.open` — Open boundary

Lines every face of a box solid with a perfectly matched layer of `thickness` (conducting walls behind it), for radiation and scattering: an anisotropic medium of stretched coordinates, s = 1 − j(σ₀/k₀)(ξ/d)², designed for 1e-6 reflection at normal incidence. A quarter to half a wavelength is typical; leave as much again between what radiates and the layer (the Huygens surface for the far field lies between them, and wants a couple of elements' distance from sources' near fields). Without `thickness`, closes the box again.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `thickness` | number | length | no | the layer's thickness |

## `source.dipole` — Dipole source

A short current element (Hertzian dipole) driving an open problem: `current` (A, peak) over `length` along `direction` at `at`.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `at` | array | length | yes | its position [x, y, z] |
| `direction` | array |  | no | its axis (default [0, 0, 1]) |
| `length` | number | length | yes | its length (the moment is current × length) |
| `current` | number |  | no | its current in amperes, peak (default 1) |

## `source.plane_wave` — Plane wave

A plane wave of 1 V/m on the model's dielectric and conducting bodies: the solve finds the field they scatter (on conductors n × E_s = −n × E_inc), its radar cross-section and the power it carries away.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `direction` | array |  | no | the direction it travels (default [0, 0, 1]) |
| `polarization` | array |  | no | its electric field's direction, across `direction` (default [1, 0, 0]) |

## `model.port.lumped` — Lumped port

A lumped (discrete) port: the feed of an antenna, a gap from `from` to `to` (usually between two conductors) across which a source of `voltage` at `phase` in series with `impedance` drives current from `from` towards `to`. solve.radiation reports its input (or, with several ports on, active) impedance, S11 against `impedance` and the power it delivers.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | yes | port name |
| `from` | array | length | yes | the gap's start [x, y, z] |
| `to` | array | length | yes | the gap's end [x, y, z] |
| `impedance` | number |  | no | the source's internal impedance in ohms (default 50) |
| `voltage` | number |  | no | the source's voltage in volts, peak (default 1) |
| `phase` | number |  | no | the source's phase in degrees (default 0) |
| `radius` | number | length | no | spread the current round a band of this radius about the gap's line (a wire's radius, for a gap cut in a wire); default 0, the line itself |

## `source.clear` — Clear sources

## `solve.radiation` — Radiation

Solves the open problem at one frequency: the field the sources radiate (or the dielectrics scatter), the power through a Huygens box between what radiates and the layer (a third of its thickness inside it, or halfway when that is nearer), with the closed form for a lone dipole (radiated power) or a lone dielectric or conducting sphere (the Mie series' scattering cross-section).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `frequency` | number | frequency | yes | the frequency |
| `order` | integer |  | no | element order: 1 or 2 (default) |

## `results.far_field` — Far field

The far field (r e^{jkr} E_θ, E_φ) of the last radiation solve at polar angles `theta` and azimuth `phi` (degrees), by the near-to-far transform of the Huygens box's equivalent currents: directivity for sources, radar cross-section for a plane wave, with the closed forms where they apply.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `theta` | array |  | no | polar angles in degrees (default 0 to 180 by 10) |
| `phi` | number |  | no | the azimuth in degrees (default 0) |
