# Commands

Generated by `cargo xtask features` (`emcraft-cli features`). Lengths are in millimetres and frequencies in gigahertz unless the session's display units say otherwise.

## `project.frequency` — Frequency band

The job's frequency band: the default for meshing by wavelength (its top), for sweeps and for port-mode previews.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `start` | number | frequency | yes | the band's start |
| `stop` | number | frequency | yes | the band's stop |

## `project.status` — Workflow status

Where each step of the workflow stands (intent, geometry, materials, excitation, boundaries, mesh, setup, run, results): done, warning, missing or stale, each with messages naming the command that fixes it. Reads the model, the mesh and the results; solves nothing.

No parameters.

## `project.estimate` — Solve estimate

The meshed model's unknowns at `order`, the factor's memory and the time per frequency: from the session's last sweep when it has one, else from a reference machine's.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `order` | integer |  | no | element order, 1 or 2 (default 2) |

## `file.save` — Save project

Saves the project as an `.emcraft` file (JSON: the model and the commands that built it, a script), to `path` or, without one, to the file it was opened from or last saved to. A path without an extension gets `.emcraft`.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | no | the file (default: the project's own) |

## `model.material.create` — Create material

A linear, isotropic material, lossless unless it has a loss tangent or dispersion. A dispersive material's permittivity is ε(ω) = εr(1 − j tan δ) + Σ χ_k(ω) over its Debye, Lorentz and Drude poles (time dependence e^{jωt}, so ε = ε′ − jε″; Taflove & Hagness, Computational Electrodynamics, 3rd ed., ch. 9); εr is then ε∞. The frequency-domain solver takes ε(ω) at each frequency, the time-domain solver its poles by auxiliary differential equations (not yet in its open problems); ports may not lie in a dispersive material, nor eigenmode cavities be filled with one.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | yes | unique name |
| `eps_r` | number |  | yes | relative permittivity εr > 0 (ε∞ with dispersion) |
| `mu_r` | number |  | no | relative permeability μr > 0 (default 1) |
| `loss_tangent` | number |  | no | dielectric loss tangent tan δ ≥ 0 (default 0): ε = εr(1 − j tan δ) |
| `debye` | array | frequency | no | Debye poles `[{"delta_eps", "frequency"}]`: χ = Δε/(1 + jω/ω_r), Δε > 0, relaxation frequency f_r = 1/(2πτ) > 0 (frequency) |
| `lorentz` | array | frequency | no | Lorentz poles `[{"delta_eps", "frequency", "damping"}]`: χ = Δε ω₀²/(ω₀² − ω² + jωγ), Δε > 0, resonance f₀ = ω₀/2π > 0, damping γ/2π > 0 (frequencies) |
| `drude` | array | frequency | no | Drude poles `[{"plasma_frequency", "damping"}]`: χ = −ω_p²/(ω² − jωγ), plasma frequency ω_p/2π > 0, damping γ/2π > 0 (frequencies) |

## `geometry.waveguide` — Rectangular waveguide

A rectangular waveguide along z with perfectly conducting walls: cross-section `width` (x) × `height` (y) from the origin, filled along z in sections, each with its own aperture across x (H-plane steps, inductive irises; neighbouring apertures must nest). A shielded planar circuit is one too: `layers` fill it from y = 0 up (a substrate), `strips` of no thickness lie on planes y = const (a microstrip on the substrate's top, a stripline between two layers; strips may end inside the box: open stubs, a stub branching off a line), `vias` are conducting posts (a via to ground, a shorting pin); its ports then take their modes from the cross-section solver. Replaces any geometry, mesh and results.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `width` | number | length | yes | broad wall a (x) |
| `height` | number | length | yes | narrow wall b (y) |
| `sections` | array |  | yes | `[{"length", "material", "width"?, "offset"?}]` from z = 0: a section may narrow the broad wall to an aperture `width` wide (lengths), starting at x = `offset` (centred when left out) |
| `layers` | array |  | no | `[{"thickness", "material"}]` from y = 0 up, across the whole guide (lengths); above them each section's material |
| `strips` | array |  | no | `[{"y", "x0", "width", "z0"?, "z1"?}]`: conducting strips of no thickness, [x0, x0 + width] × [z0, z1] on the plane y (lengths; z0, z1 the guide's ends when left out) |
| `vias` | array |  | no | `[{"x0", "z0", "wx", "wz", "y0"?, "y1"?}]`: conducting rectangular posts [x0, x0 + wx] × [y0, y1] × [z0, z0 + wz], solid metal (lengths; y0 = 0 and y1 = the height when left out: a post from the ground plane, through a strip on its way, to the top); a via from the ground to a strip ends at the strip's y |

## `geometry.solid` — Primitive body

A body of one material with conducting walls, meshed with unstructured tetrahedra: a box [0, x] × [0, y] × [0, z] (`size`), a cylinder about z from z = 0 (`radius`, `length`) or a sphere about the origin (`radius`). Its end faces (z = 0, z = length) can carry ports; a closed body is a cavity for `solve.eigenmodes`. Replaces any geometry, mesh and results.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `shape` | string |  | yes | `box`, `cylinder` or `sphere` |
| `size` | array | length | no | the box's [x, y, z] |
| `radius` | number | length | no | the cylinder's or the sphere's radius |
| `length` | number | length | no | the cylinder's length along z |
| `material` | string |  | no | the filling (default vacuum) |

## `geometry.import` — Import

Reads a part: an STL file (one body) or a 3MF package, such as SolidCraft's export with face tags (one body per object, named after it, its B-rep faces kept as faces). Triangles are grouped into faces also by the angle between neighbours, so sharp edges stay edges. One body alone becomes the region the fields fill, filled with `material`, and its faces on its lowest and highest z planes can carry ports. Several bodies lie in a box of air (`material`) `margin` beyond them all, or in the body `region` names; each is metal unless `materials` gives it another (geometry.body.material changes it later). With `open` (an antenna, a scatterer) the box is lined by a perfectly matched layer as model.open does: by default a quarter of the band's longest wavelength of air between the parts and the layer, and a layer as thick. Replaces any geometry, mesh and results.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | yes | the file (`.stl` or `.3mf`) |
| `unit` | number | length | no | an STL file's length unit in display units (default 1, i.e. the display unit); 3MF files carry their own |
| `angle` | number |  | no | neighbouring triangles turning by more than this many degrees are on different faces (default 30) |
| `material` | string |  | no | the region's filling (default vacuum) |
| `region` | string |  | no | `box` (air around the bodies; the default for several) or the name of the body that is the region (the default for one) |
| `margin` | number | length | no | the box's room around the bodies, the layer included (default a quarter of their largest extent; with `open`, a quarter wavelength of air and the layer) |
| `materials` | object |  | no | body name → material, or `metal` (the default for every body) |
| `open` | boolean |  | no | an open problem: line the box of air with a perfectly matched layer (default false) |
| `thickness` | number | length | no | the layer's thickness with `open` (default a quarter of the band's longest wavelength) |

Later bodies win where they overlap. The same shapes as geometry.solid, its origin at `at` and its z axis turned onto `axis` (dielectric bodies along z).

| `size` | array | length | no | the box's [x, y, z] (in its own axes) |
| `radius` | number | length | no | the cylinder's or the sphere's radius |
| `length` | number | length | no | the cylinder's length along its axis |
| `at` | array | length | no | where its origin goes (default [0, 0, 0]) |
| `axis` | string |  | no | `x`, `y` or `z` (default): where its own z axis points |

## `mesh.generate` — Mesh

Meshes the waveguide with tetrahedra of about `size` on a side (six per cell of a structured grid; every section boundary and aperture wall is a grid plane), graded towards the re-entrant edges of steps and irises. A solid is meshed without structure, its tetrahedra on curved walls and interfaces curved (quadratic geometry) unless `curved` is false.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `size` | number | length | no | target element size (required without `per_wavelength`; with it, the largest size) |
| `per_wavelength` | number |  | no | elements per wavelength in each material at `frequency` (λ = c/(f√(εr μr))): a solid's regions each at their own size, a waveguide at the smallest |
| `frequency` | number | frequency | no | the highest frequency the mesh must resolve (with `per_wavelength`) |
| `edge` | number |  | no | element size at step and iris edges, as a fraction of `size` (default 0.25; 1 = uniform) |
| `growth` | number |  | no | element growth away from those edges (default 1.5) |
| `strip_edge` | number |  | no | element size at strips' edges, as a fraction of `size` (default 0.05: E ∝ r^{−1/2} there; 1 = uniform) |
| `size_y` | number | length | no | element size across the narrow wall (default `size`); an H-plane device's TE10 fields do not vary along y, so one layer (the height) is exact there |
| `curved` | boolean |  | no | solids: bend the edges on curved surfaces onto them (default true; false leaves flat facets inscribed in the surface) |

## `mesh.adapt` — Adaptive mesh

Refines the mesh in passes until the S-parameters settle: each pass meshes, solves at `frequency` and compares S with the previous pass (ΔS, the largest change of any entry); it stops when ΔS < `tolerance`, after `passes`, or before the next mesh would pass the tetrahedra or unknowns limit (the last that fitted stays). A solid is refined where a residual error indicator is largest (the jumps of tangential μ⁻¹∇×E and normal εE across faces and the element residual, summed over the ports' excitations): the fewest tetrahedra holding `fraction` of its total are meshed again at half their size, graded smoothly. A structured waveguide grid is refined uniformly instead (the size divided by 1.4 a pass). The final mesh stays; solve it with solve.frequency. Open problems are not supported yet.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `size` | number | length | no | the first pass's element size (required without `per_wavelength`) |
| `per_wavelength` | number |  | no | the first pass's elements per wavelength in each material at `frequency` |
| `frequency` | number | frequency | no | the frequency to adapt at (default: the band's top) |
| `passes` | integer |  | no | the most passes, 1 to 12 (default 6) |
| `tolerance` | number |  | no | converged when ΔS, the largest change of any S entry from the previous pass, is below this (default 0.02) |
| `fraction` | number |  | no | Dörfler's θ in (0, 1]: refine the fewest tetrahedra holding this share of the error (default 0.3) |
| `order` | integer |  | no | element order: 1 or 2 (default) |
| `curved` | boolean |  | no | solids: bend the edges on curved surfaces onto them (default true) |
| `edge` | number |  | no | waveguides: element size at step and iris edges, as a fraction of the size (default 0.25) |
| `growth` | number |  | no | waveguides: element growth away from those edges (default 1.5) |
| `strip_edge` | number |  | no | waveguides: element size at strips' edges, as a fraction of the size (default 0.05) |
| `size_y` | number | length | no | waveguides: element size across the narrow wall (default the size; kept through the passes) |

## `model.walls` — Wall conductivity

The conductivity of the guide's walls, irises and steps: losses by the Leontovich surface-impedance condition (good conductors, skin depth far below the guide). Without `conductivity` the walls are perfect conductors.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `conductivity` | number |  | no | σ in S/m (copper 5.8e7); leave out for perfect conductors |

## `model.symmetry` — Symmetry plane

Cuts a waveguide symmetric about its middle (x = a/2 or y = b/2) on that plane: only the side below it is meshed and solved, the plane closed by an electric wall (a perfect conductor: tangential E = 0, the fields whose tangential E is odd about it) or a magnetic wall (tangential H = 0, normal E = 0: the fields whose tangential E is even). TE10 is kept by a magnetic wall at x = a/2 and an electric wall at y = b/2, so an H-plane iris or filter solves on a quarter with the whole model's S-parameters; ports carry only the modes of the kept parity, fields beyond the plane are shown as the images of those inside. One plane per axis (a new one replaces the old); `clear` removes one (`axis`) or all. Waveguides only; the time-domain solver refuses symmetry planes. Drops the mesh.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `axis` | string |  | no | `x` (the plane x = const) or `y` (y = const); with `clear`, the plane to remove |
| `kind` | string |  | no | `electric` (PEC wall) or `magnetic` (PMC wall) |
| `at` | number | length | no | the plane's position (default the guide's middle, the only one allowed) |
| `clear` | boolean |  | no | remove the plane across `axis`, or every plane without it |

## `model.port.create` — Create port

A waveguide port on an end face, matched to the guide's lowest modes. The first mode (TE10 in a rectangular guide, TEM in a coaxial line) is excited and read; the other modes absorb what else reaches the port. A whole rectangle or circle of one material takes the closed-form modes; any other cross-section — a coaxial line, a ridged guide, an imported polygon — has its modes solved on its triangles at each frequency (`mode_solver` numeric forces that everywhere). With `face` the port is a rectangle of a z plane inside a solid instead — a guide's closed end inside a body, say, feeding an antenna in an open box; `end` then says which side of the plane the guide lies (start: above it, end: below it).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | yes | unique name |
| `end` | string |  | yes | `start` (z = 0) or `end` (z = length); with `face`, the side the guide lies |
| `modes` | integer |  | no | modes in the port condition, 1 to 32 (default 4) |
| `face` | array | length | no | [z, x0, y0, a, b]: the rectangle [x0, x0 + a] × [y0, y0 + b] of the plane at z |
| `mode_solver` | string |  | no | `auto` (default: closed forms where they apply) or `numeric` (the cross-section solver) |
| `impedance` | number |  | no | the reference impedance (Ω) S is referred to here, for a line with one (coaxial, strip); the line's own when left out |
| `deembed` | number | length | no | de-embedding: how far inside the model S's reference plane lies from the port's face, along its line (negative: a line added outside); default 0 |

## `solve.frequency` — Frequency sweep

Solves the driven problem at each frequency, every port excited in turn by a unit wave of its first mode (TE10 in a rectangular guide): S-parameters and fields. Frequencies are `frequencies`, or `points` evenly from `start` to `stop`. Three or more are swept fast: a few are solved in full, their fields span a basis, the others are solved in it, and the worst-resolved one is added in full until every residual is within 1e-4 (S then within about 1e-10 of a full solve); `sweep` full solves each in full.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `frequencies` | array | frequency | no | the frequencies |
| `start` | number | frequency | no | first frequency |
| `stop` | number | frequency | no | last frequency |
| `points` | integer |  | no | frequencies from start to stop (default 11) |
| `order` | integer |  | no | element order: 1 (Whitney) or 2 (default) |
| `sweep` | string |  | no | `fast` (default: the reduced-basis sweep for three frequencies or more) or `full` (a full solve at each) |

## `solve.time_domain` — Time-domain solve

The S-parameters (port 1 excited) by the time-domain solver: finite integration on a hexahedral grid of cells about `cell` on a side, a TE10 pulse over the band, PML-terminated feeds, Fourier transforms at the frequencies. An independent check of the frequency-domain FEM; lossless models only. For an open model (model.open) it solves the antenna instead: its lumped ports and dipoles on a uniform grid with a CPML on all sides, the ports' impedances and S11 and the radiated power at each frequency, the far field from a Huygens box (results.far_field and view.pattern with `solver` time_domain). Gaps and dipoles must lie along grid axes.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `frequencies` | array | frequency | no | the frequencies |
| `start` | number | frequency | no | first frequency |
| `stop` | number | frequency | no | last frequency |
| `points` | integer |  | no | frequencies from start to stop (default 11) |
| `cell` | number | length | no | the cell size (default 1 mm) |
| `device` | string |  | no | where the leapfrog runs: `cpu` (the CPU's threads), `cuda` (an NVIDIA GPU) or `cubecl-cpu` (the GPU's kernels on the CPU, to check them without a GPU); default solve.device's; solve.devices lists what this machine has |
| `precision` | string |  | no | the fields' floating point on a GPU device: `single` or `double`, default solve.device's; the CPU's threads run in double |

## `solve.device` — Device

Where the solvers run from now on: `cpu` (the CPU's threads, the default), `cuda` (an NVIDIA GPU) or `cubecl-cpu` (the GPU's kernels on the CPU, to check them). On a device the time domain steps its fields in `precision`, and the frequency domain's factorizations hand their large fronts (from `min_front` rows) to it in complex double; the CPU still pivots each block and solves. Consumer GPUs run double precision slowly: on an RTX 3080 the factorization runs at about the CPU's pace. A setting of this machine, kept across projects and never saved with them.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `device` | string |  | yes | `cpu`, `cuda` or `cubecl-cpu` |
| `precision` | string |  | no | the time domain's fields: `single` (default) or `double` |
| `min_front` | integer |  | no | the factorization's fronts from this many rows go to the device (default: as before, at first 1024) |

## `solve.devices` — Devices

Where the time-domain solver can run on this machine: each device with the precisions it runs, or why it cannot run.

No parameters.

## `solve.eigenmodes` — Eigenmodes

The resonances of the guide closed at both ends by conducting walls (a cavity; ports are left out): the `count` modes nearest `near`, with Q factors from the walls' conductivity and the dielectrics' loss tangents by perturbation. Put `near` a little above the modes wanted: modes up to about √2 times it are found before the curl's null space.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `near` | number | frequency | yes | the frequency the modes are sought around |
| `count` | integer |  | no | modes, 1 to 50 (default 5) |
| `order` | integer |  | no | element order: 1 or 2 (default) |

## `results.eigenmodes` — Eigenmode table

The eigenmodes' frequencies and Q factors; for a cavity of one uniform section, the closed-form resonances too.

No parameters.

## `solve.port_modes` — Port modes

Each port's modes at one frequency, from the meshed model without solving the volume: the closed forms for a whole rectangle or circle of one material, the cross-section solver elsewhere. Per mode: the propagation constant β (radians per length unit), the effective permittivity (β/k₀)² and — for a line with one conductor besides the ground (coaxial, strip) — the characteristic impedance by power and current (Ω) when it propagates; the attenuation (dB per length unit) when it does not.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `frequency` | number | frequency | no | the frequency (default: the band's top) |
| `order` | integer |  | no | element order of the cross-section solver, 1 or 2 (default 2) |

## `results.sparameters` — S-parameters

The S-parameter table of the last sweep: each S[p][q] (at port p for a wave into port q) as real, imaginary, magnitude, dB and phase (degrees).

No parameters.

## `results.tdr` — TDR

Time-domain reflectometry from the sweep's reflection at a port (the time domain's if there is no sweep): `lowpass` — on a harmonic sweep, f_k = k Δf, for lines without a cut-off — gives the step response ρ(t), a step at each change of impedance at its round-trip delay (Z = Z0 (1 + ρ)/(1 − ρ) with the port's reference impedance); `bandpass` gives |h(t)|, a peak where each reflection comes from (guides with a cut-off). Hann-windowed, over one alias period 1/Δf.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `port` | string |  | no | the port (default the first) |
| `mode` | string |  | no | `lowpass` (default on a harmonic sweep) or `bandpass` |

## `model.open` — Open boundary

Lines every face of a box solid with a perfectly matched layer of `thickness` (conducting walls behind it), for radiation and scattering: an anisotropic medium of stretched coordinates, s = 1 − j(σ₀/k₀)(ξ/d)², designed for 1e-6 reflection at normal incidence. With `shape` sphere the solid is a sphere (centred on the origin) and its outer shell of that thickness is the layer, stretched along the radius only (r̃ = r + (1/jk₀)∫σ dr; the mesh gets an interface sphere at the layer's inner radius) — less volume round a compact radiator than a box's, and the Huygens surface a sphere inside it; sources, lumped ports and inclusions inside the inner sphere, no waveguide ports or features. A quarter to half a wavelength is typical; leave as much again between what radiates and the layer (the Huygens surface for the far field lies between them, and wants a couple of elements' distance from sources' near fields). Without `thickness`, closes the box again.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `thickness` | number | length | no | the layer's thickness |
| `reflection` | number |  | no | the reflection at normal incidence the layer's profile is designed for, 0 to 1 (default 1e-6) |
| `shape` | string |  | no | `box` (default: slabs on a box solid's faces) or `sphere` (the outer shell of a sphere solid) |

## `study.sweep` — Parameter sweep

Sweeps a variable: for each value the model is rebuilt from the history with it (meshed when the history meshes), solved by `solve` (`{"command": "solve.frequency", "params": {…}}`, any solve command) and its results collected: S-parameters at the solve's frequencies, eigenmodes' frequencies, the solve's other numbers. The session's model is left as it was. A point that cannot be built or solved is reported in its row; cancelling stops at the next point.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `variable` | string |  | yes | the variable swept |
| `values` | array |  | no | its values (at most 101) |
| `start` | number |  | no | the first value (without `values`) |
| `stop` | number |  | no | the last value |
| `points` | integer |  | no | values from start to stop (default 5, at most 101) |
| `solve` | object |  | yes | the solve at each point: {"command", "params"} |
| `outputs` | array |  | no | the S-parameters kept, such as ["s11", "s21"] (default all) |

## `study.optimize` — Optimize

Finds the variables' values within their bounds that minimize a goal, by the Nelder–Mead simplex (Comput. J. 7(4):308–313, 1965) on the range scaled to [0, 1], from the current values; each point is the model rebuilt from the history and solved by `solve`. Goals (`type`): `min_max_db` (the largest |S| over the frequencies, default s11: a reflection), `max_min_db` (the smallest |S|, default s21: a transmission), `target_db` (|S| at `target` dB), `eigenfrequency` (mode `mode`, default 1, at `target` in display units), `maximize` or `minimize` (a number the solve gives: `quantity`). The model is left at the best point (undo goes back); every evaluation is kept.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `variables` | array |  | yes | the variables varied: [{"name", "min", "max"}] (at most 8) |
| `goal` | object |  | yes | what to minimize: {"type", "parameter", "target", "mode", "quantity"} |
| `solve` | object |  | yes | the solve at each point: {"command", "params"} |
| `max_evaluations` | integer |  | no | the most solves (default 50, at most 500) |
| `tolerance` | number |  | no | the simplex's size at which it stops, a share of each range (default 1e-3) |
