# Commands

Generated by `cargo xtask features` (`emcraft-cli features`). Lengths are in millimetres and frequencies in gigahertz unless the session's display units say otherwise.

## `pcb.load` — Load PCB data

Loads native PCB routing data in the session's length units. Replaces the model; geometry is checked before committing. Nets, stackup, segments, vias and saved filled copper are embedded in project history.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `data` | object |  | yes | PCB object: name, layers [{name,z,eps_below,loss_below,copper}] (loss_below the tan δ below, default 0; copper the copper's thickness, default 0 a sheet — on the top or bottom layer it stands that thick into the air, its loss with model.walls then the thick strip's, not a sheet's singular edges'), segments [{id,net,layer,start,end,width}], vias [{net,at,layers,diameter}], copper [{net,layer,polygon}], notes; any number may be an expression ("=h") |

## `pcb.import` — Import PCB

Reads a KiCad board's tracks (arcs as chords), vias, footprints' copper pads (a plated hole a via), explicit dielectric stackup (each ply's epsilon_r and loss_tangent) and saved filled copper. Unfilled zones are not treated as copper; mask and copper thickness are excluded. Imported data is embedded so reopening needs no source file.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | yes | KiCad .kicad_pcb file, at most 64 MiB |
| `stackup` | array |  | no | optional copper layers [{name,z,eps_below,loss_below,copper}], lengths in display units; replaces file stackup (copper the thickness on the top or bottom layer, default 0) |

## `pcb.region` — PCB region

Sets the part of the board the finite elements solve: a box round the copper (or `net`'s routes) by `margin`, or between the corners `lo` and `hi`, from `below` under the lowest layer to `above` over the highest, closed by conducting walls. The model's geometry becomes that box, the region's lower-left corner at the origin, the board's x and y the model's x and z, its height the model's y with the lowest layer `below` over the floor, each substrate a material `substrate εr …`; its ports go on the box's sides with model.port.create (cleared here). mesh.generate then meshes the copper of every layer in one triangulation, extruded through the substrates and the air, the copper conducting sheets of no thickness inside.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `net` | string |  | no | the net whose routes the box surrounds (default all the copper) |
| `margin` | number | length | no | the margin round the copper (default 5 thicknesses of the thinnest outer dielectric) |
| `lo` | array | length | no | the lower-left corner [x, y] in the board's coordinates (default the copper's less the margin) |
| `hi` | array | length | no | the upper-right corner [x, y] (default the copper's plus the margin) |
| `above` | number | length | no | the air over the highest layer (default 5 thicknesses of the thinnest outer dielectric) |
| `below` | number | length | no | the air under the lowest layer (default 5 thicknesses of the thinnest outer dielectric; 0 puts the lowest layer on the conducting floor) |

## `pcb.port` — PCB port

Puts a lumped port at a trace's end in the board's region (pcb.region): a sheet the trace's width wide from its reference — the nearest layer below with another net's copper under that end, else above, else the box's floor — to the trace, its source in series with `impedance`. With lumped ports and no waveguide ports, solve.frequency gives S of the lumped ports, their waves referred to their impedances.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | yes | port name |
| `segment` | string |  | yes | the segment's id |
| `end` | string |  | no | `start` or `end` of the segment (default start) |
| `impedance` | number |  | no | the port's impedance in ohms (default 50) |

## `pcb.element` — PCB lumped element

A lumped element on a layer of the board's region (pcb.region), from the board point `from` to `to` — a chip resistor bridging two traces, a capacitor across a gap in one — as model.element.create puts one: its resistance, inductance and capacitance in series or in parallel, a sheet `width` wide across the gap's line when given.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | yes | element name |
| `layer` | string |  | yes | the copper layer it sits on |
| `from` | array | length | yes | the gap's start on the board [x, y] |
| `to` | array | length | yes | the gap's end on the board [x, y] |
| `resistance` | number |  | no | R in ohms (default 0: none) |
| `inductance` | number |  | no | L in nanohenries (default 0: none) |
| `capacitance` | number |  | no | C in picofarads (default 0: none) |
| `arrangement` | string |  | no | `series` (default) or `parallel` |
| `width` | number | length | no | a sheet this wide across the gap's line (a chip's width); default the line itself |

## `pcb.inspect` — Inspect PCB route

Screens the selected net's routed segments and filled reference copper and reports exact line/polygon coverage gaps, nearby parallel signals, topology and via-transition limitations. Only valid simple outer microstrip routes get a lossless quasi-static line approximation: impedance, delay, S11/S21 and TDR. Screening is not a solved return-current map, full-wave model, calculated crosstalk or compliance verdict.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `net` | string |  | no | signal net (default: selected net, or first routed signal) |
| `ground` | string |  | no | reference net (default the confirmed conditions', else GND) |
| `reference` | number |  | no | source/load impedance in ohms (default the confirmed conditions', else 50) |
| `stop` | number | frequency | no | top frequency (default the confirmed conditions', else 1 GHz) |
| `points` | integer |  | no | harmonic sweep points, 4..128 (default 64) |

## `pcb.conditions` — PCB diagnosis conditions

Confirms the conditions of the chosen route's diagnosis: the reference net (`ground`, a net of the board), the reference impedance and the top frequency; each left out keeps the confirmed one (else GND, 50 Ω, 1 GHz). The diagnosis is then ready: the Set conditions stage is done and pcb.inspect runs with them. Choosing another route keeps them. Saved with the project.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `ground` | string |  | no | reference net |
| `reference` | number |  | no | source/load impedance in ohms, 0.1..10000 |
| `stop` | number | frequency | no | top frequency, at most 1 THz |

## `project.setup` — Confirm the run's settings

Confirms the run's settings for the job's kind of analysis (or `kind`), as the Setup step shows them: a sweep's band (`start`, `stop`), `points` and element `order`; the time domain's band, `points`, `cell` and the ports to `excite`; the eigenmodes' `count` near `frequency` and `order`; a radiation solve's `frequency` and `order`; a system's band, `points` and the `frequency` its budget is shown at. The job is then ready: the Setup step is done and Run (solve.run) runs them. Choosing another kind (project.analysis) takes them back. The band also sets meshing by wavelength (its top) and the port previews. Undo goes back.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `kind` | string |  | no | the kind of analysis (default the job's): `frequency`, `eigenmodes`, `radiation`, `time_domain` or `system`; choosing it as project.analysis does |
| `start` | number | frequency | no | the band's start (a sweep, the time domain, a system) |
| `stop` | number | frequency | no | the band's stop (a sweep, the time domain, a system) |
| `points` | integer |  | no | the frequency points (default 101) |
| `order` | integer |  | no | element order, 1 or 2 (default 2) |
| `count` | integer |  | no | the eigenmodes to find, 1 to 50 (default 5) |
| `frequency` | number | frequency | no | the eigenmodes' search frequency (near), the radiation solve's, or a system's budget's (default the band's centre) |
| `cell` | number | length | no | the time domain's cell size (default 1 mm) |
| `excite` | array |  | no | the time domain's ports to excite, by name (default the first) |

## `project.analysis` — Analysis

The kind of analysis the job is set up for, chosen at its start (`pcb`: routed PCB signal-quality and return-reference inspection via pcb.inspect, without a FEM mesh or accelerator setup): `frequency` (S-parameters between ports over the band, solve.frequency), `eigenmodes` (a closed resonator's modes, nothing driving it, solve.eigenmodes), `radiation` (an antenna or a scatterer in an open boundary, solve.radiation) or `time_domain` (a pulse over the band, solve.time_domain). The workflow's checks (project.status) follow it: a resonator needs no excitation and its ports are left out, radiation wants the open boundary and a source or a lumped port, a sweep and the time domain want ports, the time domain no mesh (project.status lists the steps a kind does without under `not_needed`). Until one is chosen the kind is inferred from the model (PCB diagnosis for a loaded PCB, eigenmodes without excitation, radiation with sources, lumped ports or an open boundary, else a sweep). Choosing another kind than the confirmed settings' takes them back (project.setup again). The results stay as they are. Undo goes back.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `kind` | string |  | yes | `frequency`, `eigenmodes`, `radiation`, `time_domain` or `pcb` |

## `project.status` — Workflow status

Where each step of the workflow stands (intent, geometry, materials, excitation, boundaries, mesh, setup, run, results): done, to do (`todo`), waiting, warning, missing (needs attention) or stale (out of date), each with messages naming the command that fixes it. Reads the model, the mesh and the results; solves nothing.

No parameters.

## `project.estimate` — Solve estimate

How long a run will take, before it starts: `command` with `params` (a solve, solve.run, mesh.adapt, study.sweep or study.optimize), else the confirmed settings' run (project.setup), else the project's latest run, else a sweep. The total `seconds` (the frequencies of a sweep — a fast sweep solving a few in full —, the eigenmodes, the adaptive passes, the time domain's cells and steps, a study's points), what it counts (`what`), and for a frequency-domain solve the meshed model's unknowns at `order`, the factor's memory and the seconds of one solve. `basis` says where the numbers come from: `measured` (scaled from this session's own last sweep, on this machine) or `reference` (a reference machine's). Reads the model only: cheap, and the same set-up gives the same numbers.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `order` | integer |  | no | element order, 1 or 2 (default the run's, else 2) |
| `command` | string |  | no | the run to estimate: a solve command, mesh.adapt, study.sweep or study.optimize (default the latest run) |
| `params` | object |  | no | its parameters, as the command takes them |

## `file.save` — Save project

Saves the project as an `.emcraft` file (version 0.1, docs/project-file.md: a package of the commands that built the model, the runs, the views, the analysis history, the mesh and the results — S-parameters, tables and, with `fields`, the field vectors — their numbers little-endian arrays), to `path` or, without one, to the file it was opened from or last saved to. A path without an extension gets `.emcraft`. With `copy` it writes a copy to `path` and leaves the project's own file, name and unsaved state as they were (an autosave).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | no | the file (default: the project's own; required with `copy`) |
| `copy` | boolean |  | no | write a copy only: the project keeps its file and stays unsaved (default false) |
| `fields` | boolean |  | no | write the field vectors too, up to 1 GB of them (default true): opened, the fields show without solving again |

## `file.new` — New project

Replaces the session with an empty project (vacuum only), keeping the display units; undo goes back.

No parameters.

## `file.open` — Open project

Opens a project saved by file.save (`.emcraft`, version 0.1; any other version is refused): its commands are replayed (the mesh commands recorded, not run: the file's own mesh is put on the model) and its results come back as they were, no solve again — those that no longer fit are left out, with why (`left_out`); its runs (project.runs) come back too. With `original`, `path` is a copy of that project (an autosave being recovered): the project takes the original's file, unsaved where it differs from what that file holds. Undo goes back to the project before, its file included.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | yes | the file |
| `original` | string |  | no | the project file `path` is a copy of: the project's own file from now on |

## `project.runs` — Runs

The project's runs: the last solve of each solve command that succeeded, the latest last, each with its parameters in the display units now (as the command takes them: they reproduce the run) and the units it was given in. Saved with the project and restored by file.open without running them; a run with other parameters than the saved one leaves the project unsaved.

No parameters.

## `project.values` — Current values

The parameters that reproduce the model's current state for `command`, in the display units now, for an edit dialog to open on: the band, the units, the device, the walls, the open boundary, a symmetry plane (`axis`, default the first), the periodic boundaries, the waveguide, a primitive solid; an item's for its edit command (`name` a material's or a port's, `body` a body's, `index` a source's); the mesh commands' as the history last ran them; a solve command's as its last run (project.runs). Running the command with them leaves the model as it is (an item edit to the last bit). A command with no current state gives an empty object.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `command` | string |  | yes | the command, such as `model.walls` or `model.port.edit` |
| `name` | string |  | no | the item of an item's edit command: a material's or a port's name |
| `body` | string |  | no | geometry.body.edit's body |
| `index` | integer |  | no | source.edit's source, 1 = the first |
| `stage` | string |  | no | system.stage.edit's stage, by name |
| `axis` | string |  | no | model.symmetry's plane: `x`, `y` or `z` (default the first there is) |

## `results.import` — Import measured S

Reads a Touchstone file (version 1 or 2: .s1p, .s2p, …; S, Y or Z in RI, MA or dB, any frequency unit) and keeps its S-parameters with the project as a measurement, drawn over the S-parameter chart (and on the Smith chart) and compared with the sweep. Its name is the file's stem unless `name` is given; one of the same name is replaced. Y and Z are turned into S on the file's reference impedances. A two-port's noise data (F_min, Γ_opt, R_n; version 1 after its S, version 2 under [Noise Data]) is kept with it: results.noise reads the device's noise figure from it and circuit.cascade chains it. At most 8 measurements, 64 MB a file. `template:<file>` reads a template's own data (`template:adsb-patch.s1p`, `template:adsb-bandpass.s2p`: the adsb-patch antenna's and adsb-bandpass filter's S as EMCraft solves them).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `path` | string |  | yes | the Touchstone file |
| `name` | string |  | no | the measurement's name (default the file's stem) |

## `results.measured` — Compare with measurement

A measurement against the sweep, entry by entry of S over the sweep's frequencies within the measurement's band (the measurement interpolated linearly between its frequencies): the largest and RMS |ΔS| (complex), the largest difference of |S| in dB and the frequency where |ΔS| is largest, and the worst entry.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | no | the measurement (default the only one) |

## `results.network` — Network matrices

The sweep's (or a measurement's) S as a network: the impedance matrix Z = √z₀ (I + S)(I − S)⁻¹ √z₀, the admittance Y = Z⁻¹, a two-port's chain matrix ABCD (Pozar, Microwave Engineering, §4.3–4.4), or S itself, at each frequency or the one nearest `frequency`, as rows of [re, im]; and each port's input impedance with the others matched, z₀ (1 + Sᵢᵢ)/(1 − Sᵢᵢ). z₀ is each port's reference impedance (a TEM or terminal port's); a waveguide port has none, so its entries are normalized (z₀ = 1) unless `impedance` gives one.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `kind` | string |  | no | `z` (default), `y`, `abcd` or `s` |
| `data` | string |  | no | `sweep` (default) or a measurement's name |
| `frequency` | number | frequency | no | the frequency nearest this one only (default every one) |
| `impedance` | number |  | no | z₀ in Ω for ports without a reference impedance (waveguide ports) |

## `results.mixed_mode` — Mixed-mode S

The sweep's (or a measurement's) S of ports paired as differential lines, in mixed mode (Bockelman & Eisenstadt, IEEE Trans. MTT 43(7), 1995): each pair's differential wave (a₊ − a₋)/√2 and common wave (a₊ + a₋)/√2, S_mm = M S Mᵀ, its waves ordered d1, d2, …, c1, c2, …, then the ports left unpaired; so Sdd21 is the entry (d2, d1) and Scd21 the conversion (c2, d1). At each frequency or the one nearest `frequency`, as rows of [re, im].

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `pairs` | array |  | no | pairs of ports [positive, negative] from 1, such as [[1, 3], [2, 4]] (default 1 with 2, 3 with 4, …) |
| `data` | string |  | no | `sweep` (default) or a measurement's name |
| `frequency` | number | frequency | no | the frequency nearest this one only (default every one) |

## `results.equivalent` — Equivalent circuit

Lumped branches fitted to the sweep's (or a measurement's) network (Pozar, Microwave Engineering, §4.4): a one-port's impedance as R, L and C in series (`series`) or its admittance as G, L and C in parallel (`shunt`); a two-port as a π (shunt branches Y11 + Y12 and Y22 + Y12 in parallel, the series branch −1/Y12) or a T (series arms Z11 − Z12 and Z22 − Z12, the shunt branch Z12). Each branch's loss is the mean of its real part and its L and C (each ≥ 0, or left out) the least-squares fit of its reactive part over the frequencies, with the RMS relative error. The fitted network's S is kept as a measurement named `name`, drawn over the chart. z₀ is each port's reference impedance; a waveguide port takes `impedance` (default 50 Ω).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `topology` | string |  | no | `series`, `shunt` (a one-port's; the default for one port), `pi` (the default for two) or `t` |
| `data` | string |  | no | `sweep` (default) or a measurement's name |
| `port` | integer |  | no | the one-port's port from 1 (default 1), the others matched |
| `impedance` | number |  | no | z₀ in Ω for ports without a reference impedance (default 50) |
| `name` | string |  | no | the name the fitted network's S is kept under (default `equivalent`) |

## `circuit.cascade` — Cascade

Two-ports in a chain, port 2 of each to port 1 of the next, by their chain (ABCD) matrices (Pozar, Microwave Engineering, §4.4): `{"type": "data", "data": "sweep"}` (the sweep or a measurement, `flip` swapping its ports), `{"type": "series" | "shunt", "resistance", "inductance", "capacitance", "arrangement"}` (Ω, nH, pF, `series` or `parallel`, as model.element.create's), `{"type": "line", "impedance", "length", "eps_r", "attenuation", "at", "tan_delta"}` (Ω, the display length; lossless unless `attenuation` — a conductor's, dB per display length, growing as √(f/`at`) from frequency `at` when given — or `tan_delta`, a dielectric's, π f √εr tan δ / c with εr the line's effective one), `{"type": "amplifier", "gain", "noise_figure"}` (dB: an ideal amplifier, matched and unilateral on `impedance`, its noise figure from a matched source, an uncorrelated noise wave kT₀(F − 1) at its input: Γ_opt = 0, R_n = Z₀(F − 1)/4), `{"type": "attenuator", "loss"}` (dB, matched) — system.stage.add's stages. Its noise is chained too, by Hillbrand and Russer's chain correlation matrices (IEEE Trans. CAS-23(4), 1976): a measurement's noise data (an amplifier's), a passive S block's by Twiss's equilibrium kT(I − SSᴴ) (the sweep's, or a measurement without noise data; one that gains has no noise then, and says why), a lumped element's resistance's thermal noise, a lossy line's from its loss, all at `temperature`, a lossless line none; the reply's `noise` gives the chain's least and greatest noise figure from a source of `impedance` (results.noise on the kept result gives it at every frequency): from `source`, a one-port measurement's impedance (an antenna's terminals from solve.radiation_sweep, a .s1p), when given; with `bandwidth`, the receiver's sensitivity too (results.noise's budget). Its S on `impedance` at each frequency of its first S block (the others interpolated linearly; an error outside their bands), or from `start` to `stop` in `points` without one, kept as a measurement named `name` and drawn over the chart.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `blocks` | array |  | yes | the two-ports from port 1 on, at most 32 |
| `impedance` | number |  | no | the reference impedance in Ω of the result's ports, and of S blocks' ports that have none (default 50) |
| `start` | number | frequency | no | the first frequency, without an S block |
| `stop` | number | frequency | no | the last frequency, without an S block |
| `points` | integer |  | no | frequencies without an S block (default 201) |
| `name` | string |  | no | the name the result is kept under (default `cascade`) |
| `temperature` | number |  | no | the physical temperature in K of the passive blocks' noise (default 290) |
| `source` | string |  | no | a one-port measurement whose impedance is the source's (an antenna's S11 from solve.radiation_sweep, a .s1p); default the input's reference impedance |

## `results.coupling` — Extract coupling matrix

The folded coupling matrix of N resonators whose response best fits the sweep's (or a measurement's) S11 and S21 over the frequencies mapped to the low-pass ω = (f₀/Δf)(f/f₀ − f₀/f), then synthesized as filter.synthesize does. By default (`magnitude`) from |S| alone: a lossless filter's |S11|²/|S21|² is ε²F(ω)²/P(ω)², fitted by least squares for the reflection zeros (F's roots) and transmission zeros (P's), so the feed lines between the ports and the resonators, which turn only the phase, need no removal. `cauchy` fits complex S instead (Macchiarella & Traina, IEEE MWCL 16(5), 2006: S11 E − F = 0, S21 E − P = 0), each port's phase loading, linear in ω, removed as the slope the rational model fits best; `cauchy_plain` takes S as it is. Either way F's and P's roots are taken onto the axis and E rebuilt lossless. `cutoff` maps the guide frequency √(f² − f_c²) instead (a waveguide filter's resonators: their phase goes as β); `start` and `stop` keep the fit to a narrower band. The reply gives the matrix, the zeros, ε, the loading (cauchy) and the RMS difference of |S11| and |S21| between model and data; the model's response is kept as a measurement named `name`.

## `model.material.create` — Create material

A linear, isotropic material, lossless unless it has a loss tangent (dielectric or magnetic) or dispersion. A dispersive material's permittivity is ε(ω) = εr(1 − j tan δ) + Σ χ_k(ω) over its Debye, Lorentz and Drude poles (time dependence e^{jωt}, so ε = ε′ − jε″; Taflove & Hagness, Computational Electrodynamics, 3rd ed., ch. 9); εr is then ε∞. Its permeability is μr(1 − j tan δm). The frequency-domain solver takes ε(ω) at each frequency, the time-domain solver its poles by auxiliary differential equations and its loss tangents as conductivities matched at the centre of its band (exact there, tan δ·f_ref/f elsewhere). A port may lie in a lossy or dispersive material that fills its cross-section, or cross several materials one of which is lossy or dispersive (a microstrip or stripline on a lossy substrate: hybrid lossy modes solved on the cross-section at each frequency): its modes then attenuate (γ = α + jβ) and S is read as pseudo-waves referred to each port's wave impedance (Marks & Williams 1992); eigenmode cavities may not be filled with a dispersive material.

## `geometry.waveguide` — Rectangular waveguide

A rectangular waveguide along z with perfectly conducting walls: cross-section `width` (x) × `height` (y) from the origin, filled along z in sections, each with its own aperture across x (H-plane steps, inductive irises; neighbouring apertures must nest). Replaces any geometry, mesh and results.

## `geometry.import` — Import

Reads a part: an STL file (one body) or a 3MF package, such as SolidCraft's export with face tags (one body per build item, named after its object, its B-rep faces kept as faces; objects made of components flattened, their transforms composed, and objects in other model parts of the package read). Each face's exact surface (plane, cylinder, sphere, cone, torus) is recovered from its vertices where one fits them to 1e-6 of the body's size, so second-order elements bend onto curved faces; the reply counts them under `curved`. Triangles are grouped into faces also by the angle between neighbours, so sharp edges stay edges. Every body is metal unless `materials` gives it another (geometry.body.material changes it later; an imported part's walls and region body too, reading the part again). The region (ADR 0005): the body given `interior` (or named by `region`: its shape is the air solved, its faces on its lowest and highest z planes can carry ports); else the air the metal bodies enclose, when they enclose any (as `region` `cavity`); else a box of air (`material`) `margin` beyond them all (the reply's `cavity` says why no cavity was found). With `region` `cavity` the part is drawn as its metal (a block with a channel milled through it): the region is the air the metal bodies enclose — their bounding box less them, split into connected pieces, each piece kept that reaches the box only across one axis, the channel's (its lowest and highest faces there, where the ports go: z, y or x, whichever such pieces hold the most air; the reply's `pieces.axis`), the air around a part that is not a box dropped; `keep` `largest` keeps only the largest piece. The metal bodies become the region's walls, bodies of other materials lie in it. With `open` (an antenna, a scatterer) the box is lined by a perfectly matched layer as model.open does: by default a quarter of the band's longest wavelength of air between the parts and the layer, and a layer as thick. Replaces any geometry, mesh and results.

## `mesh.adapt` — Adaptive mesh

Refines the mesh in passes until the S-parameters (or an open problem's far field) settle: each pass meshes, solves at `frequency` and compares S with the previous pass (ΔS, the largest change of any entry); it stops when ΔS < `tolerance`, after `passes`, or before the next mesh would pass the tetrahedra or unknowns limit (the last that fitted stays). A solid is refined where a residual error indicator is largest (the jumps of tangential μ⁻¹∇×E and normal εE across faces and the element residual, summed over the ports' excitations): the fewest tetrahedra holding `fraction` of its total are meshed again at half their size, graded smoothly. A structured waveguide grid is refined uniformly instead (the size divided by 1.4 a pass). Open problems (model.open) are adapted too, each pass solved as solve.radiation solves it: the indicator leaves out the perfectly matched layer (never refined, so it keeps its thickness and the size it was meshed at) and the tetrahedra at a current element or a line gap, and takes a plane wave's incident field as the scattered field's data; with lumped ports or a waveguide feed the passes compare their reflections (ΔS), with sources alone the far field (`quantity` far_field in the reply). The final mesh stays; solve it with solve.frequency (open problems: solve.radiation).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `size` | number | length | no | the first pass's element size (required without `per_wavelength`) |
| `per_wavelength` | number |  | no | the first pass's elements per wavelength in each material at `frequency` |
| `frequency` | number | frequency | no | the frequency to adapt at (default: the band's top) |
| `passes` | integer |  | no | the most passes, 1 to 12 (default 6) |
| `tolerance` | number |  | no | converged when the change from the previous pass is below this (default 0.02): ΔS, the largest change of any S entry (open problems: of the lumped ports' and the feed's reflections); for an open problem driven by sources alone (dipoles, a plane wave), the far field's relative change ‖F − F′‖/‖F′‖ of r e^{jkr}(E_θ, E_φ) over 48 directions (θ 15° to 165° every 30°, φ every 45°), which tracks the radiated or scattered power and the pattern |
| `fraction` | number |  | no | Dörfler's θ in (0, 1]: refine the fewest tetrahedra holding this share of the error (default 0.3) |
| `order` | integer |  | no | element order: 1 or 2 (default) |
| `curved` | boolean |  | no | solids: bend the edges on curved surfaces onto them (default true) |
| `edge` | number |  | no | waveguides: element size at step and iris edges, as a fraction of the size (default 0.25) |
| `growth` | number |  | no | waveguides: element growth away from those edges (default 1.5) |
| `strip_edge` | number |  | no | waveguides: element size at strips' edges, as a fraction of the size (default 0.05) |
| `strip_end` | number |  | no | waveguides: element size at strips' ends along z, as a fraction of the size (default `strip_edge`) |

## `model.walls` — Walls

The conductivity and thickness of the guide's walls, irises and steps. The metal is never meshed: only the inside is, and the walls are a surface impedance on it, so a thickness costs no unknowns. With `conductivity`, losses by the Leontovich condition (good conductors, skin depth far below the guide), through a wall of `thickness` with free space behind it (Z_s = η_c(η₀ + η_c tanh γt)/(η_c + η₀ tanh γt): thinner than a few skin depths it loses more; the time-domain solver takes walls as thick). Without `conductivity` the walls are perfect conductors; the thickness is then drawn round the guide only. Leave `thickness` out for infinitely thick walls drawn flush. With `roughness` (the surface's rms height Δ) the walls' surface impedance is multiplied by the Hammerstad–Jensen factor 1 + (2/π) arctan(1.4 (Δ/δ)²): 1 while Δ is well below the skin depth δ, towards 2 above it (frequency-domain solvers; the time domain refuses rough walls).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `conductivity` | number |  | no | σ in S/m (copper 5.8e7); leave out for perfect conductors |
| `thickness` | number | length | no | the walls' thickness; leave out for infinitely thick walls |
| `roughness` | number | length | no | the rms height of the walls' roughness (with `conductivity`); leave out for smooth walls |

## `model.symmetry` — Symmetry plane

Cuts a model symmetric about its middle on that plane: only the side below it is meshed and solved, the plane closed by an electric wall (a perfect conductor: tangential E = 0, the fields whose tangential E is odd about it) or a magnetic wall (tangential H = 0, normal E = 0: the fields whose tangential E is even). A waveguide is cut across x (x = a/2) or y (y = b/2): TE10 is kept by a magnetic wall at x = a/2 and an electric wall at y = b/2, so an H-plane iris or filter solves on a quarter with the whole model's S-parameters. A solid is cut across x, y or z when its body, features and inclusions mirror about the plane and the plane cuts every port's face through its middle (ports on faces; not yet with an open boundary, lumped ports or sources): an H-plane tee or bend about its mid-height with an electric wall. Ports carry only the modes of the kept parity; fields beyond the plane are shown as the images of those inside. One plane per axis (a new one replaces the old); `clear` removes one (`axis`) or all. The time-domain solver refuses symmetry planes. Drops the mesh.

|---|---|---|---|---|
| `axis` | string |  | no | `x`, `y` or `z` (the plane across that axis); with `clear`, the plane to remove |
| `kind` | string |  | no | `electric` (PEC wall) or `magnetic` (PMC wall) |
| `at` | number | length | no | the plane's position (default the model's middle, the only one allowed) |
| `clear` | boolean |  | no | remove the plane across `axis`, or every plane without it |

## `solve.revolution` — Body of revolution

The eigenmodes of a closed cavity invariant under rotation about the z axis, from its meridian profile: the polygon `points` [[r, z], …] (r ≥ 0; an edge on r = 0 is the axis, every other edge a perfect conductor) filled with one material, or without `points` the model's own (its solid, features and inclusions each a body of revolution about z — a cylinder along z on the axis, a sphere centred on it or an imported surface turned about it — combined as the model combines them, inclusions dielectric or conducting; the curves in chords of `size`), meshed in triangles of about `size` and solved per azimuthal order `m` on the half-plane — a 2D problem in place of the 3D one (hybrid edge/nodal elements, Lee–Wilkins–Mittra). The `count` modes of order `m` nearest `frequency`, lowest first. The model is left as it is.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `points` | array | length | no | the profile's corners [[r, z], …] in order, at least three, r ≥ 0 (default the model's profile) |
| `frequency` | number | frequency | yes | the frequency to look near |
| `m` | integer |  | no | the azimuthal order, 0 to 64: the fields go as e^{−jmφ} (default 0) |
| `count` | integer |  | no | the modes, 1 to 50 (default 5) |
| `size` | number | length | no | the triangles' size (default a tenth of the wavelength at `frequency`, at most a twentieth of the profile) |
| `eps_r` | number |  | no | the filling's relative permittivity (default 1) |
| `mu_r` | number |  | no | the filling's relative permeability (default 1) |

## `solve.revolution.frequency` — Body of revolution S

The S-parameters of the model as a body of revolution about z (its profile as solve.revolution takes it) between its ports on its lowest and highest ends, in one azimuthal order `m` on the meridian half-plane: each port's modes of that order (TE_mp, TM_mp of its circle, in closed form) in its condition, S between their first modes (m = 1: TE11, the whole's dominant mode in either polarization; m = 0: TM01). Triangles of about `size` (default a fortieth of the wavelength at the top frequency, at most a twentieth of the profile). The model is left as it is.

| `stop` | number | frequency | no | last frequency (default the band's stop) |
| `points` | integer |  | no | frequencies from `start` to `stop` (default 11) |
| `m` | integer |  | no | the azimuthal order, 0 to 64 (default 1) |
| `size` | number | length | no | the triangles' size |

## `solve.revolution.bloch` — Bloch wave of a cell

The model as one cell of a periodic body of revolution (its ports on its two ends, one period apart, the same guide on both): the Bloch wave of its infinite repetition in azimuthal order `m` at each frequency, γ = α + jβ, from the cell's generalized scattering matrix between `modes` modes on each end (the transfer matrix's eigenvalue e^{−γp} of the least-attenuated wave going +z; Collin §9.2), β unwrapped along the sweep. In a stop band α > 0. Kept as the session's result with the cell's S: results.pulse takes it over any `length` of the guide. The model is left as it is.

## `solve.revolution.radiation` — Body of revolution radiation

The open model as a body of revolution about z at one frequency: its cylinder (layer shape box: the wall and both ends lined) or sphere (layer shape sphere: the outer shell) lined by the model's perfectly matched layer (model.open), driven by its one source — a dipole on the axis along z (order m = 0) or a plane wave along ±z (orders ±1, the field the dielectrics scatter) — solved on the meridian half-plane, and the far field by the near-to-far transform of a Huygens surface a third of the layer's thickness inside it, turned about the axis: the power out through it and, at polar angles `theta` (degrees, φ = 0 the dipole's or the wave's E-plane), r e^{jkr} E_θ and E_φ with the directivity (a dipole) or the bistatic radar cross-section in the E- and H-planes (a plane wave). Triangles of about `size` (default a twenty-fifth of the wavelength in the densest material). The model is left as it is.

| `theta` | array |  | no | polar angles, degrees (default 0 to 180 by 15) |
| `size` | number | length | no | the triangles' size |

## `solve.revolution.time_domain` — Body of revolution ring-down

The closed model as a body of revolution about z rung in the time domain in one azimuthal order `m` on the meridian half-plane's (r, z) Yee grid of square-ish cells about `cell` (the model's filling at each cell's middle, conductors staircased; Chen–Mittra–Harms): a Gaussian-modulated pulse over the band from `start` to `stop` (default the model's), the ringing for `periods` periods of the band's middle Fourier-transformed, its resonances the spectrum's peaks. A cross-check of solve.revolution's eigenmodes by another method. The model is left as it is.

| `periods` | number |  | no | how long it rings, in periods of the band's middle, 10 to 20000 (default 300): the resolution is about 1/(that time) |

## `solve.cyclic` — Cyclic modes

The cavity modes of a rotationally symmetric model (model.rotation) from its meshed sector, per harmonic m: the `count` lowest eigenfrequencies of each above the null space, by shift-invert subspace iteration on the phase-tied (Hermitian) eigenproblem. Without `m`, the harmonics 0 to n/2 (m and n − m have the same frequencies: the fields turning either way). Put `frequency` a little above the highest mode wanted. The model is left as it is.

| `m` | integer |  | no | one harmonic, 0 to n − 1 (default 0 to n/2) |
| `count` | integer |  | no | modes per harmonic, 1 to 20 (default 4) |
| `order` | integer |  | no | element order: 1 or 2 (default) |

## `solve.harmonics` — Harmonics sweep

A rotationally symmetric model (model.rotation) with ports on its axis, solved on its sector in each harmonic m at `frequencies` (or `points` from `start` to `stop`): each harmonic's S between the ports' first modes (the rotating e^{−jνφ}, ν ≡ m mod n; a harmonic whose first modes do not all propagate is left out at that frequency), and the dominant pair — the mode of order +1 in harmonic 1 and its twin −1 in n − 1 — as the whole model's standing polarizations c (cos) and s (sin): S_cc = S_ss = (S₊ + S₋)/2, S_sc and S_cs = ±j(S₊ − S₋)/2, nonzero only when the model turns one rotation's wave differently from the other's (a twisted or chiral part). The model is left as it is.

## `model.symmetry.auto` — Find symmetries

Searches every symmetry of the model in one go and sets those that change no answer: the mirror planes about each axis' middle whose walls the ports decide (their TE10: magnetic across a broad side, electric across a narrow one; two at most); with no port (an eigenmode search), the planes found with every combination of walls to solve (`every_wall`: solve.eigenmodes solves each on the same mesh and merges their modes, so none is lost). The former planes and rotation are cleared first. The reply says what was set (`planes`, `every_wall`), the share of the model each solve takes (`fraction`) and what was found but left out, with why (`skipped`): the rotation about z would keep one harmonic of the whole (model.rotation sets it). Finding nothing is not an error. Translation (an infinite array's cell) is not a symmetry of a finite model: model.periodic sets it.

No parameters.

## `model.symmetry.find` — Find symmetry

Finds the planes the model is symmetric about (its geometry, materials and ports; each axis' middle) and sets them, at most two: each wall from what its ports' TE10 asks for (magnetic across a broad side, electric across a narrow one). Without ports (an eigenmode search) either wall keeps a family of modes: `kind` chooses it. Refused when no plane is found.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `kind` | string |  | no | the wall for a plane no port decides: `electric` or `magnetic` |

## `model.rotation` — Rotational symmetry

Makes the model the same turned by 2π/`n` about an axis along z through `centre`: only one sector is meshed and solved, its two cut faces tied by e^{−j2πm/n} (the fields of the whole going as e^{−jm′φ} with m′ ≡ `m` mod n). The solid must be a cylinder or a sphere about its own axis, a box square across z (n = 4) or an imported surface whose vertices turn onto its vertices, and each feature (geometry.feature) must turn onto one of its combination (itself about the axis, or another, as posts round it), each inclusion onto one of its filling (those inside the sector are meshed as they are, those across its cut faces — a rod or a puck on the axis — cut with it, their caps on the cut faces each other's turn, and those outside are their images'); not yet with symmetry planes, periodic or open boundaries, lumped ports or sources. A cavity's modes per harmonic come from solve.cyclic; a cylinder's ports on its ends (circles on the axis) take the rotating modes e^{−jνφ}, ν ≡ m mod n, in closed form, and solve.frequency gives harmonic m's S-parameters (TE11+ for m = 1, TM01 for m = 0). `clear` removes it. Drops the mesh, unless only `m` changes.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `n` | integer |  | no | the sectors in a turn, 3 to 64 (required unless `clear`) |
| `m` | integer |  | no | the harmonic, 0 to n − 1 (default 0) |
| `centre` | array | length | no | the axis' [x, y] (default the solid's middle) |
| `clear` | boolean |  | no | remove the rotational symmetry |

## `model.rotation.find` — Find rotation

Finds the rotational symmetry about an axis along z the model has and sets it: a cylinder's or a sphere's own axis (round: any number of sectors), a square box's middle (quarters), or the centroid of an imported surface's vertices with the most sectors, up to 64, that turn it onto itself. The reply's `group` names it (C∞, Cₙ). Refused when none is found or the model holds what a sector cannot carry yet (as model.rotation).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `n` | integer |  | no | the sectors: any of 3 to 64 for a round solid (default 4), a divisor of the most else (default the most) |
| `m` | integer |  | no | the harmonic, 0 to n − 1 (default 0) |

## `model.periodic` — Periodic boundaries

Makes the model the unit cell of an infinite array: the faces x = 0 and x = a (`x`), y = 0 and y = b (`y`) or z = 0 and z = length (`z`) tied by Floquet's condition E(r + L) = e^{−jψ}E(r) (master/slave elimination; the system is then solved by LU, being Hermitian rather than complex symmetric). Across x and y the phases come from a plane wave incident at `theta` from the z axis and azimuth `phi` from x, in the first port's medium; the ports on the cell's ends become Floquet ports (the harmonics TE and TM (m, n), the (0, 0) of `polarization` excited and read, the rest absorbing). Along z the cell is a period of a guide whose dispersion `solve.dispersion` finds (no ports). Waveguide geometries only (the structured mesh's opposite faces match); not with symmetry planes, open boundaries, lumped ports or the time domain. `clear` removes them.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `x` | boolean |  | no | tie x = 0 and x = a (default true; as before when set) |
| `y` | boolean |  | no | tie y = 0 and y = b (default true) |
| `z` | boolean |  | no | tie z = 0 and z = length (default false; no ports then) |
| `theta` | number |  | no | incidence angle from the z axis in degrees, 0 to below 90 (default 0) |
| `phi` | number |  | no | incidence azimuth from the x axis in degrees (default 0) |
| `polarization` | string |  | no | `te` (E across the plane of incidence, default) or `tm` |
| `clear` | boolean |  | no | remove the periodic boundaries |

## `model.port.create` — Create port

A waveguide port on an end face, matched to the guide's lowest modes. The first mode (TE10 in a rectangular guide, TEM in a coaxial line) is excited and read; the other modes absorb what else reaches the port. A whole rectangle or circle of one material takes the closed-form modes; any other cross-section — a coaxial line, a ridged guide, an imported polygon — has its modes solved on its triangles at each frequency (`mode_solver` numeric forces that everywhere). With `face` the port is a rectangle of an axis plane of a solid instead — across z by default, across x or y with `axis` (an arm of a bend or a tee ending on a side of the solid, a guide's closed end inside a body feeding an antenna in an open box); `end` then says which side of the plane the guide lies (start: above it along the axis, end: below it). An imported cavity whose channel runs along x or y takes its port on the channel's opening at `end` without `face`. Its modes are the rectangle's along its own sides, in the order x, y, z (an x face: a along y, b along z; a y face: a along x, b along z). A cross-section holding several strips (coupled lines) is a terminal port: one S entry per strip, `<port>:1`, `<port>:2`, … from the lowest x, its quasi-TEM modes (one per strip, all excited) converted to the strips' voltages and currents and their waves referred to `impedance` (50 Ω by default); `terminals` modal reads its first mode only (and is needed in a lossy cross-section, where terminal ports are not supported yet).

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `name` | string |  | yes | unique name (without `:`) |
| `end` | string |  | yes | `start` (z = 0) or `end` (z = length); with `face`, the side the guide lies |
| `modes` | integer |  | no | modes in the port condition, 1 to 32 (default 4) |
| `face` | array | length | no | [at, u0, v0, a, b]: the rectangle [u0, u0 + a] × [v0, v0 + b] of the plane at `at` across `axis`, u and v its other two axes in the order x, y, z (across z: [z, x0, y0, a, b]) |
| `axis` | string |  | no | the axis `face` lies across: `x`, `y` or `z` (default) |
| `mode_solver` | string |  | no | `auto` (default: closed forms where they apply) or `numeric` (the cross-section solver) |
| `impedance` | number |  | no | the reference impedance (Ω) S is referred to here, for a line with one (coaxial, strip); the line's own when left out |
| `deembed` | number | length | no | de-embedding: how far inside the model S's reference plane lies from the port's face, along its line (negative: a line added outside); default 0 |
| `terminals` | string |  | no | `auto` (default: a cross-section holding two strips or more is one terminal per strip, named `<port>:<k>` from the lowest x, each referred to `impedance` or 50 Ω) or `modal` (the first mode only) |

## `solve.frequency` — Frequency sweep

Solves the driven problem at each frequency, every port excited in turn by a unit wave of its first mode (TE10 in a rectangular guide), a terminal port by each of its strips' modes (S then has an entry per strip, `ports` names them): S-parameters and fields. Frequencies are `frequencies`, or `points` evenly from `start` to `stop`. Three or more are swept fast: a few are solved in full, their fields span a basis, the others are solved in it, and the worst-resolved one is added in full until every residual is within 1e-4 (S then within about 1e-10 of a full solve); `sweep` full solves each in full. Each point's `full` says whether it was solved in full, `solved_in_full` counts them.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `frequencies` | array | frequency | no | the frequencies |
| `start` | number | frequency | no | first frequency |
| `stop` | number | frequency | no | last frequency |
| `points` | integer |  | no | frequencies from start to stop (default 101) |
| `order` | integer |  | no | element order: 1 (Whitney) or 2 (default) |
| `sweep` | string |  | no | `fast` (default: the reduced-basis sweep for three frequencies or more) or `full` (a full solve at each) |
| `solver` | string |  | no | `auto` (default: factored whole, or for second-order elements beyond 2 million unknowns iterative), `direct` or `iterative` (GMRES preconditioned by the first-order part factored, order 2 only) |

## `solve.refine` — Refine sweep

The project's run becomes the merged sweep (solve.frequency with its frequencies listed), so running it again gives the same sweep. Needs a sweep of the model as it is.

## `solve.time_domain` — Time domain

The S-parameters (port 1 excited) by the time-domain solver: finite integration on a hexahedral grid of cells about `cell` on a side, a TE10 pulse over the band, PML-terminated feeds, Fourier transforms at the frequencies. An independent check of the frequency-domain FEM. A solid (geometry.solid with its bodies) is staircased on a grid through its faces, its ports' edges and its bodies' bounds, each waveguide port a rectangle of one material on a face of the solid's bounding box with a feed and PML outward, its TE10 along the broad side; each port of `excite` is excited in turn (S in the reply as s<out><in>), with perfect walls, on the CPU's threads. Losses: a loss tangent (dielectric or magnetic) becomes a conductivity matched at the band's centre (`loss_reference` in the reply), so the material solved is εr − jσ/ω, tan δ exactly there and tan δ·f_ref/f elsewhere; walls of finite conductivity (model.walls) take the surface-impedance condition; ports may be lossy or dispersive (their complex propagation constant normalises S). For an open model (model.open) it solves the antenna instead: its lumped ports and dipoles (or a plane wave along a grid axis, by a total-field/scattered-field split round the bodies: the scattering and radar cross-sections) on a uniform grid with a CPML on all sides, the ports' impedances and S11 and the radiated power at each frequency, the far field from a Huygens box (results.far_field and view.pattern with `solver` time_domain), with lossy, dispersive and magnetic bodies but perfect conductors. Gaps and dipoles must lie along grid axes; gaps in lossy or dispersive materials are refused.

|---|---|---|---|---|
| `frequencies` | array | frequency | no | the frequencies |
| `start` | number | frequency | no | first frequency |
| `stop` | number | frequency | no | last frequency |
| `points` | integer |  | no | frequencies from start to stop (default 101) |
| `cell` | number | length | no | the cell size (default 1 mm) |
| `device` | string |  | no | where the leapfrog runs: `cpu` (the CPU's threads), `cuda` (an NVIDIA GPU) or `cubecl-cpu` (the GPU's kernels on the CPU, to check them without a GPU); default solve.device's; solve.devices lists what this machine has |
| `precision` | string |  | no | the fields' floating point on a GPU device: `single` or `double`, default solve.device's; the CPU's threads run in double |
| `excite` | array |  | no | a solid's ports to excite, by name, one run each (default the first): the columns of S they give |

## `solve.bloch` — Bloch waves of a cell

The model as one cell of a periodic guide solved in 3D (its two waveguide ports on its two ends, one period apart along z, the same guide on both — a helically corrugated guide, say): at each frequency its generalized scattering matrix between every mode of both ports, the far port's modes written in the near port's basis (their fields compared on the faces), and the transfer matrix's eigenvalues e^{−γp} (Collin §9.2): the first `waves` waves going +z at the first frequency (the propagating ones by ascending β, then the decaying ones by ascending α), each followed along the sweep (its near-end amplitudes most nearly parallel to its last), γ = α + jβ, β continued from its strongest mode's. Kept as the session's Bloch waves: results.pulse takes one (`wave`) over any `length`. The ports' `modes` set how many modes carry the coupling between cells (whole degenerate pairs). The model is left as it is.

## `solve.time_domain.pulse` — Pulse in the time domain

A chirped Gaussian pulse launched into a waveguide's port 1 by the time-domain solver and measured at port 2 (both the same guide): the incident and transmitted power envelopes (the incident's peak 1, by I/Q demodulation at the carrier), their widths at half power, the compression and the delay between the peaks. The direct check of results.pulse, which makes a pulse from the S-parameters: with a solved transmission (a sweep's, say) the reply's `predicted` is the same incident wave through it, measured alike, and `agreement` the two compressions' ratio. The pulse's band, the carrier ± (|bandwidth| + 1/width), must lie above the ports' cut-off.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `frequency` | number | frequency | yes | the carrier |
| `width` | number |  | yes | the input's width at half power, ns |
| `bandwidth` | number | frequency | no | the band the chirp sweeps over the width, rising (> 0) or falling (< 0); default 0, no chirp |
| `cell` | number | length | no | the cell size (default 1 mm) |

## `solve.device` — Device

Where the solvers run from now on: `cpu` (the CPU's threads, the default), `cuda` (an NVIDIA GPU) or `cubecl-cpu` (the GPU's kernels on the CPU, to check them: in builds with the `cubecl-cpu` feature, which the released apps leave out). ## `solve.eigenmodes` — Eigenmodes

With symmetry planes found for every wall (model.symmetry.auto with no port), each combination of their walls is solved on the same mesh and the `count` modes nearest `near` of them all kept, each read in its own system. The resonances of the guide closed at both ends by conducting walls (a cavity; ports are left out): the `count` modes nearest `near`, with Q factors from the walls' conductivity and the dielectrics' loss tangents by perturbation. Put `near` a little above the modes wanted: modes up to about √2 times it are found before the curl's null space.

| `order` | integer |  | no | element order: 1 or 2 (default) |

## `solve.dispersion` — Dispersion diagram

The Bloch modes of the periodic cell (model.periodic), its walls perfectly conducting and its ports left out: at each phase per period ψ from `from` to `to` along `axis` (the other periodic axes at phase 0), the `bands` lowest eigenfrequencies, by shift-invert subspace iteration on the phase-shifted (Hermitian) eigenproblem. Put `near` a little above the highest band wanted: modes up to about √2 times it are found. For a guide periodic along z whose sections fill its cross-section, results.dispersion adds the closed form (TE/TM harmonics of an empty guide; TE10's Bloch bands of a loaded one).

## `results.pulse` — Pulse compression

A chirped Gaussian pulse through the solved two-port: its transmission S(f) from the sweep (a body of revolution's, else the time domain's) applied to the pulse's spectrum about its carrier and turned back into time — the input's and output's power envelopes, the compression (the output's peak power over the input's), their widths at half power, the output's peak time, and the guide's group delay and its slope D at the carrier with the chirp that compresses best, −1/D. ## `model.open` — Open boundary

Lines every face of a box solid with a perfectly matched layer of `thickness` (conducting walls behind it), for radiation and scattering: an anisotropic medium of stretched coordinates, s = 1 − j(σ₀/k₀)(ξ/d)², designed for 1e-6 reflection at normal incidence. With `shape` sphere the solid is a sphere (centred on the origin) and its outer shell of that thickness is the layer, stretched along the radius only (r̃ = r + (1/jk₀)∫σ dr; the mesh gets an interface sphere at the layer's inner radius) — less volume round a compact radiator than a box's, and the Huygens surface a sphere inside it; sources, lumped ports and inclusions inside the inner sphere, no waveguide ports or features. A quarter to half a wavelength is typical; leave as much again between what radiates and the layer (the Huygens surface for the far field lies between them, and wants a couple of elements' distance from sources' near fields). Without `thickness`, closes the box again.

| `thickness` | number | length | no | the layer's thickness |
| `reflection` | number |  | no | the reflection at normal incidence the layer's profile is designed for, 0 to 1 (default 1e-6) |
| `shape` | string |  | no | `box` (default: slabs on a box solid's faces) or `sphere` (the outer shell of a sphere solid) |

## `model.element.create` — Lumped element

Drops every result. Undo goes back.

## `study.sweep` — Parameter sweep

Sweeps a variable, or several on a grid: for each value (each point of the grid: every combination of the variables' values, the last varying fastest) the model is rebuilt from the history with it (meshed when the history meshes), solved by `solve` (`{"command": "solve.frequency", "params": {…}}`, any solve command) and its results collected: S-parameters at the solve's frequencies, eigenmodes' frequencies, the solve's other numbers. One variable's rows carry its `value`; a grid's rows carry `values` in the order of `variables`, and the reply the grid's values of each variable. The session's model is left as it was. A point that cannot be built or solved is reported in its row; cancelling stops at the next point. With `surrogate` ({"budget": N}) only N points are solved — the grid point nearest the centre, then each the farthest from those chosen (2d + 1 in all), then each where a Gaussian-process surrogate of the rows solved is least sure (its largest variance; Sacks et al., Statist. Sci. 4(4):409–435, 1989) — and every other point is predicted from them: each row output (|S| in dB at each frequency, eigenmodes, the solve's numbers) by one Gaussian process sharing the kernel (Matérn 5/2, a length scale per variable by the marginal likelihood; Rasmussen & Williams, Gaussian Processes for Machine Learning, 2006), its row marked `predicted` with `db` and `sigma_db` per S-parameter, `modes_sigma` and `scalars_sigma`; solved rows are as without it, and the reply's `surrogate` counts both and gives the length scales.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `variable` | string |  | no | the variable swept (or give `variables`) |
| `variables` | array |  | no | several variables swept on a grid: [{"name", "values"} or {"name", "start", "stop", "points"}] (at most 4, at most 400 points in all) |
| `values` | array |  | no | its values (at most 101) |
| `start` | number |  | no | the first value (without `values`) |
| `stop` | number |  | no | the last value |
| `points` | integer |  | no | values from start to stop (default 5, at most 101) |
| `solve` | object |  | yes | the solve at each point: {"command", "params"} |
| `outputs` | array |  | no | the S-parameters kept, such as ["s11", "s21"] (default all) |
| `surrogate` | object |  | no | solve only some points and predict the rest: {"budget": N}, N from 2 to the grid's points (a grid of 3 or more) |

## `study.tolerance` — Tolerance analysis

Monte Carlo tolerance analysis: each variable drawn about its value as it stands — normal with its `sigma`, or uniform within ± its `tolerance` — independently, `samples` times (a generator of its own seeded by `seed`, so the same draws every time); at each draw the model is rebuilt from the history (meshed when the history meshes) and solved by `solve`. The reply gives each S-parameter's mean, σ, least and greatest |S| in dB at each frequency over the draws, and with `spec` the yield — the share of the draws meeting every bound (|S| at most `max_db` or at least `min_db`, over `start`–`stop` or the whole sweep) — with its 95 % Wilson interval. The draws are kept as the study: the Study view draws each one, their mean and the bounds.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `variables` | array |  | yes | the variables drawn: [{"name": "w", "sigma": 0.05}] (normal) or [{"name": "w", "tolerance": 0.1}] (uniform within ±), in the variables' units (at most 8) |
| `samples` | integer |  | no | the draws (default 50, 2 to 400) |
| `seed` | integer |  | no | the generator's seed (default 1): another seed, other draws |
| `solve` | object |  | yes | the solve at each point: {"command", "params"} |
| `outputs` | array |  | no | the S-parameters kept, such as ["s11", "s21"] (default all) |
| `spec` | array |  | no | bounds for the yield: [{"output": "s11", "max_db": -15, "start": 9, "stop": 11}] or `min_db` (|S| at least); frequencies in the display unit (at most 16) |

## `study.optimize` — Optimize

Finds the variables' values within their bounds that minimize a goal, by the Nelder–Mead simplex (Comput. J. 7(4):308–313, 1965) on the range scaled to [0, 1], from the current values; each point is the model rebuilt from the history and solved by `solve`. Goals (`type`): `min_max_db` (the largest |S| over the frequencies, default s11: a reflection), `max_min_db` (the smallest |S|, default s21: a transmission), `target_db` (|S| at `target` dB), `eigenfrequency` (mode `mode`, default 1, at `target` in display units), `maximize` or `minimize` (a number the solve gives: `quantity`). The model is left at the best point (undo goes back); every evaluation is kept. `method` `bayesian` searches instead by Bayesian optimization (Jones, Schonlau & Welch, J. Global Optim. 13:455–492, 1998): the current values and 2d Halton points solved, then each time the point of the largest expected improvement under a Gaussian-process surrogate of every value solved (Matérn 5/2, a length scale per variable by the marginal likelihood), until that improvement falls below `tolerance` × the spread of the values solved or the solves run out; every value reported is a solve, and the reply's `best.predicted` gives the surrogate's goal ± σ there and `surrogate` its length scales. The reply's `method` says which ran.

| Parameter | Type | Unit | Required | Description |
|---|---|---|---|---|
| `variables` | array |  | yes | the variables varied: [{"name", "min", "max"}] (at most 8) |
| `goal` | object |  | yes | what to minimize: {"type", "parameter", "target", "mode", "quantity"} |
| `solve` | object |  | yes | the solve at each point: {"command", "params"} |
| `max_evaluations` | integer |  | no | the most solves (default 50, at most 500) |
| `tolerance` | number |  | no | where it stops (default 1e-3): the simplex's size, a share of each range; Bayesian, the expected improvement, a share of the spread of the goal's values solved |
| `method` | string |  | no | `simplex` (Nelder–Mead, the default) or `bayesian` (a Gaussian-process surrogate choosing each solve) |
