# Dielectric step

A WR-90 waveguide filled for 12 mm with PTFE (εr = 2.1) and empty for the next 18 mm, ports at
both ends. Both sections have the same cross-section, so TE10 meets TE10 at the step and no
other mode is excited: the junction reflects Γ = (β1 − β2)/(β1 + β2), where
β = √(k0² εr − (π/a)²). The S-parameters are power waves, normalised to each port's own
TE10 impedance, so |S11|² + |S21|² = 1 although the ports' media differ.

References computed from the closed form (ABCD matrices of the two lines).
