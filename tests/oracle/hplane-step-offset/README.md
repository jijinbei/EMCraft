# Asymmetric H-plane step

WR-90 (a = 22.86 mm) narrowing to a 16 mm wide guide that keeps the x = 0 wall: a step on one
side only, so the even and odd TE_m0 modes all couple and the port planes of the two guides
have different apertures (the 16 mm guide's TE10 cut-off is 9.37 GHz). The S-parameters are
power waves, |S11|² + |S21|² = 1.

Reference: mode matching with 640 modes in the wide guide (and 448 in the narrow one, in
proportion to the widths).
