# Pillbox cavity as a body of revolution

A closed cylinder of radius 10 mm and length 15 mm, solved on its meridian half-plane (the
rectangle 0 ≤ r ≤ 10, 0 ≤ z ≤ 15 mm, the edge on r = 0 the axis) one azimuthal order at a
time by `solve.revolution`: m = 0 gives the TM01p family, m = 1 TE111 and TM110. Each mode is
compared with the closed form; the 3D solve of the same cavity is the `cylinder-cavity` case.
