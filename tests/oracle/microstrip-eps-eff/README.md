# Microstrip effective permittivity

A strip of no thickness on an alumina substrate (εr = 9.8, h = 0.635 mm, W = 0.6 mm, about 50 Ω)
in a shielding box large enough to leave the line nearly open, at 1 GHz where the quasi-TEM mode
is close to its static limit. The port's cross-section holds the substrate and the strip; its
first mode's (β/k0)² is compared with Hammerstad and Jensen's fit (a published benchmark, within
0.2 % of exact). `solve.port_modes` gives it without solving the volume.
