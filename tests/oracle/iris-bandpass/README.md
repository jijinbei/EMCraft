# Inductive-iris band-pass filter

Three WR-90 cavities (15, 16.75 and 15 mm) between four 2 mm thick centred irises with
apertures of 12.75, 9.25, 9.25 and 12.75 mm, fed by 15 mm of guide on each side: a
direct-coupled cavity filter passing 9.75–10.25 GHz with better than 20 dB return loss and
17 dB of rejection 1 GHz either side. The model is the `iris-bandpass` sample: second-order
elements of 3 mm graded to 0.3 mm at the irises' edges, one element layer across the narrow
wall (the TE_m0 fields of an H-plane device do not vary along y, so one layer is exact there).

Reference: mode matching through all eight iris faces with 640 modes in the guide.
