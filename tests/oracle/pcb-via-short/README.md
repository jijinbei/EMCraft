# Microstrip shorted by a via

A microstrip 4 mm from its wave port to a 0.4 mm via down to its ground floor. The via is a
barrel through the substrate (its prisms left out, its walls conducting) under a pad the trace's
width. S11's phase is compared with the line's 2βL and the via's inductance (Goldfarb and
Pucel's formula), all evaluated apart from the solver.
