# Gap array

Two lumped gaps, 1 mm long along z and 15 mm apart along x, each driven by 1 A in phase (a
current source: 1 GV behind 1 GΩ), at 10 GHz in an 80 mm box lined with a 15 mm perfectly
matched layer. The pair is a two-element array of Hertzian dipoles with an exact pattern and
exact mutual impedances: its broadside directivity, a side-lobe value, the null along the pair
and each gap's active resistance are compared with them.
